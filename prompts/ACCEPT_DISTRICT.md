# Локальная приёмка «Района» на Mac

Ты продолжаешь Iva Games как локальный исполнитель. Владелец уже разрешил разработку «Района», разные карты, обязательных ботов и проверки. Доведи фактическую локальную приёмку и исправь найденные дефекты; не ограничивайся запуском команд. Публичный выпуск — отдельный этап.

## Источник и ограничения

Репозиторий `decorum-guy/iva-games`. Рабочая ветка `feat/district-first-playable`, [PR №16](https://github.com/decorum-guy/iva-games/pull/16), первоначально поверх `feat/iva-chat-ops` / PR №15. Получи актуальные refs и запиши точный SHA. Не считай старую сводку доказательством текущего main. Если PR уже принят, используй проверенного потомка с тем же функционалом; не откатывай на старый head.

Прочитай `AGENTS.md`, `docs/iva-games/AGENT_ROLES.md`, `docs/iva-games/PROJECT_STATUS.md`, `games/district/STATUS.md`, `RULES_V0_2.md`, `MAPS.md`, `VALIDATION_V0_2.md` и фактический код. Gemini отдельно готовит идеи: не заменяй ими v0.2, пока владелец не выбрал следующую редакцию.

Работай в отдельном worktree/ветке, сохрани пользовательские изменения и процессы. Не останавливай действующие REMORSE, Форсаж и портал на 4173/4185/4197/4198/5175 или иных занятых портах. Не используй `scripts/iva-local-demo.sh start`, если его фиксированные порты уже заняты. Не меняй SSH, DNS, бот-токены и production. Локальная файловая почта/тестовые аккаунты достаточны; реальная рассылка не нужна.

## Изолированный запуск

Установи зависимости закреплённым lockfile, запусти `npm run district:maps`, `npm run district:test`, TypeScript/ESLint и `npm run build:foundation`. Если меняешь общий код, пройди общий `check` и соответствующую регрессию. Проверь свободный порт, например **4326**, и отдельную папку `.runtime/district-acceptance`. Собранный backend умеет обслуживать портал сам; для приёмки второй dev-сервер не обязателен:

```sh
NODE_ENV=development \
PLATFORM_HOST=127.0.0.1 PLATFORM_PORT=4326 \
PORTAL_ORIGIN=http://127.0.0.1:4326 \
PLATFORM_DATABASE_PATH=.runtime/district-acceptance/platform.sqlite \
PLATFORM_LAB_DATABASE_PATH=.runtime/district-acceptance/sessions.sqlite \
PORTAL_DIST_DIRECTORY=apps/portal/dist \
MAIL_MODE=file MAIL_FILE_DIRECTORY=.runtime/district-acceptance/mail \
TELEGRAM_AUTH_ENABLED=false TELEGRAM_ENABLED=false \
node dist-platform/main.js
```

Если порт занят, выбери свободный и согласованно измени origin/port. Организуй запуск отдельного процесса привычным для Mac способом и запиши команды статуса/остановки только этой демонстрации. Не теряй существующие базы. Создай локальные демонстрационные аккаунты, подтверди их через созданные файловые письма; секреты — только в защищённых локальных файлах/Keychain, вне Git и отчёта.

## Приёмка

1. Через UI создай комнаты на разных картах. Проверь все три превью, сохранение выбора, смену карты со сбросом готовности и невозможность смены после старта. Начатая партия после перезапуска должна использовать тот же снимок.
2. Сыграй до результата: один человек + бот; один человек + три бота; два независимых человеческих аккаунта; смешанная комната. Проверь разные уровни бота. В остальных составах/картах используй автоматические прогоны и отдельно укажи, где был настоящий пользовательский проход.
3. Выполни банк, прямой обмен, встречные условия, замену/отказ, обмен участками, парк с общей оплатой, неподписанный парк и его отмену. Убедись, что собеседник видит точные условия, а третий игрок не получает приватные поля.
4. Сделай сохранённую и подтверждённую ставку, пропуск и равенство ставок; построй и улучши разные здания. Проверь событие, доход, личную цель, капитал и одинаковый итог у всех клиентов.
5. Проверь потерю ответа и повтор одной команды, отключение/возврат сети, перезапуск сервера, истечение срока, явный выход и возврат, выход последнего человека. Не подменяй неподключённого человека стратегическим ботом.
6. Пройди RU/EN, узкий экран, клавиатуру и фокус окон. Физический телефон при его наличии; эмуляцию подпиши отдельно. Оцени читаемость карты, удобство переговоров и времени решения. Справка «Как играть» не выдаётся за интерактивный туториал.

Повторяемые команды: `npm run portal:e2e -- --workers=1`, `npm run district:browser`, `npm run district:simulate`. Браузерная smoke-команда запускает собственный сервер на свободном порту с временными базами; не направляй её на действующие пользовательские данные.

## Баланс и итог

Синтетические 108 партий выявили редкое использование парков: «Зелёный двор» 1/34, «Соавтор района» 0/16 у текущих политик. Это вопрос к ботам и правилам, а не установленный диагноз. Попробуй осмысленную парковую стратегию, переговоры и разные планы застройки. Не меняй цены автоматически; фиксируй наблюдение, воспроизводимый пример и предложение следующей редакции.

Публикуй законченные исправления отдельно без force-push. Обнови `games/district/STATUS.md`, отчёт и общую очередь, указав точные ревизии/команды, прошедшие проверки, ошибки, ограничения и следующую задачу. QA-скриншоты/видео/базы держи вне Git и Actions artifacts. Оставь одну отдельную демонстрационную вкладку с реально работающей игрой и объясни владельцу, как начать партию. Не отмечай production выпущенным, пока не выполнено отдельное размещение.
