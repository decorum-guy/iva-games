# Добавить карту «Района» по описанию

**Описание владельца** — <ЖЕЛАЕМЫЙ ВИД И ИГРОВОЙ ЗАМЫСЕЛ>.

В `decorum-guy/iva-games` получи актуальные refs. Прочитай [инструкции проекта](../AGENTS.md), [формат карт](../games/district/MAPS.md), [правила островов](../games/district/RULES_V0_3.md) и [арт-направление](../games/district/MAP_ART_DIRECTION.md).

1. Опиши силуэт, размещение общественных мест и задуманный выбор для игроков. Создай один файл `games/district/maps/<id>.<version>.json` со схемой 2, RU/EN и пятью связными зонами. Оставь опубликованные версии на месте и проверь предыдущие снимки.
2. Запусти `npm run district:maps -- --base <base-ref>`, `npm run district:test` и `npm run build:foundation`. Проверь автоматическое появление превью и новой карты при создании комнаты.
3. Проверь старт, закрепление снимка, возврат и партии на 2–4 места. Используй `npm run district:simulate -- --islands` для сравнимых прогонов. Покажи пустой и заполненный вид и запиши измеренные изменения по соседству, доходу и целям.
4. Опубликуй карту и отчёт отдельным коммитом без force-push. Если пожелание требует новых правил, зафиксируй его для отдельной версии. Публикация игрового сервера проводится отдельно.

Результат — карта, ревизия, ссылка на демонстрацию, измерения и границы проверки.
