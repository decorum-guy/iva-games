## Установка, код и сборки

Среда повторного запуска: Linux, Node.js **24.22.3**, npm **11.19.1**. Установка выполнена в новой отдельной копии через `npm ci --offline --no-audit --no-fund`. Затем явно выполнен `npm rebuild better-sqlite3 --foreground-scripts`: автоматическое исполнение install script этой зависимости не было разрешено настройкой npm. Тесты использовали настоящую файловую SQLite.

## Граница результата и передача

Пакетный перенос и его публикация завершены. Текущее устройство: `games/chess/remorse`, `games/chess/overdrive`, `packages/engine-sdk`, `apps/server`. Общие команды выполняются из корня с одним lockfile.

В этом проходе не выполнялись браузерные E2E, визуальная или слуховая приёмка, проверка физического телефона, Docker-сборка, публичный VPS/TLS и нагрузочное испытание. Поэтому ни браузерная готовность Форсажа, ни вместимость коммерческого сервера здесь не подтверждаются. Ограничения proxy rate limit и пересылки полной истории не исправлялись.

`main`, DNS, работающая Mac-сборка и пользовательские базы не изменялись. Работа над платформой остаётся отдельной. Подробные журналы, JSON-протоколы и временные базы сохранены в игнорируемой `.qa/`; в Git и GitHub Actions artifacts они не добавлялись.
