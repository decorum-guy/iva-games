# WILDCARD / «Джокер» — полные рабочие правила v0.1

Ruleset ID: `wildcard-v0.1-draft`. Дата: 25 ноября 2026 года.

Статус: детерминированный проект правил для следующего аудита. Пользователь выбрал карточные шахматы, редкости, стартовую и периодическую выдачу, запрет клетки и заморозку фигуры или линии. Состав колоды, числа, стоимость карт, исключения, сроки и порядок разрешения ниже — решения ассистента v0.1, а не отдельно утверждённый пользователем баланс. Партии и проверка баланса ещё не проводились.

Общая геометрия шахмат, обычная расстановка, право хода белых, стандартные движения, сдача и ничья по соглашению определяются в [COMMON_RULES.md](COMMON_RULES.md). Этот документ имеет приоритет там, где прямо меняет обычные правила. Ни одна карта не разрешает физически взять короля.

## 1. Цель и основа

У каждого игрока обычная шахматная армия и личная скрытая колода одинакового состава. Победа — мат с учётом всех доступных противнику допустимых карточных и обычных ответов. Король остаётся королём; соседство королей запрещено всегда.

За свой ход игрок выбирает одну из трёх форм действия:

1. Обычный шахматный ход без карты.
2. Одну обычную карту и связанный с ней обязательный шахматный ход.
3. Одну редкую, эпическую или легендарную карту вместо всего шахматного хода.

Разрешена не более чем одна карта за целый ход. Реакционных карт на чужом ходу, контркарт, торговли картами и отдельной маны в v0.1 нет. Игрок не может произвольно пропустить ход; законное применение карты третьего вида само является ходом.

Доступная в руке карта не создаёт предварительного шаха. Угрозы определяются геометрией текущей доски и уже действующими состояниями. Например, возможность сыграть «Перестановку судеб» на следующем ходу сама по себе не меняет карту атак.

## 2. Термины и состояние

- **Действие перемещения** — обычное перемещение, взятие, рокировка либо единая карточная перестановка.
- **Ход игрока** — вся атомарная команда, включая карту, обязательное перемещение, удаления, превращения и истечение эффектов.
- **Полный раунд** — один ход белых и один ход чёрных.
- **Серийный номер хода C** — число уже завершённых ходов игроков. Изначально C = 0. После первого хода белых C = 1, после первого хода чёрных C = 2.
- **Армирование эффекта** — фиксация его срока при завершении хода, на котором сыграна карта. Ход активации не считается одним из последующих ходов длительности.
- **Фигура** имеет стабильный ID, владельца, тип, клетку, исторические права движения и действующие состояния. Перемещение, заморозка и превращение не создают новый ID.
- **Экземпляр карты** имеет собственный ID и тип. Два одинаковых экземпляра дают одинаковые игровые возможности; их ID нужен для команд и истории, а не для различения повторений позиции.

В полном состоянии хранятся доска, сторона хода, C, очередь будущих карт каждой стороны, рука и сброс каждой стороны, активные эффекты и сроки, права рокировки и двойного шага пешек, en passant, счётчики повторений и тихих ходов, результат и версия правил.

## 3. Колода, редкости и добор

### 3.1 Состав каждой личной колоды

| Тип карты | Редкость | Экземпляров | Цена применения |
|---|---|---:|---|
| Карантин | Обычная | 6 | Карта, затем обязательный ход |
| Задний ход | Обычная | 6 | Карта, затем обязательный обратный ход выбранной пешкой |
| Криостаз | Редкая | 4 | Весь ход |
| Ледниковый фронт | Редкая | 3 | Весь ход |
| Долг крови | Редкая | 3 | Весь ход |
| Тектоника | Эпическая | 2 | Весь ход |
| Перестановка судеб | Легендарная | 1 | Весь ход |
| **Всего** | | **25** | |

Редкость задаёт количество экземпляров. Она не гарантирует, что карта полезнее другой в любой позиции. Состав фиксирован для этого ruleset; составление собственной колоды отсутствует.

### 3.2 Подготовка партии

1. Создать две независимые колоды по таблице.
2. Независимо и равномерно перемешать каждую. Порядок не подстраивается под сторону, уровень ИИ, позицию или результат предыдущих партий.
3. Выдать верхние три карты каждому игроку. Стартовой пересдачи нет.
4. Поставить обычную начальную позицию, назначить ход белым, C = 0 и зарегистрировать начальную устойчивую позицию один раз.

Порядок обеих колод скрыт в том числе от их владельцев. В v0.1 колода перемешивается только при создании партии. Сброс обратно не замешивается.

### 3.3 Периодический добор

После каждого третьего завершённого полного раунда, то есть при C = 6, 12, 18 и далее, обе стороны получают по одной верхней карте своей колоды. Добор выполняется после разрешения хода и истечения эффектов, но до проверки мата и пата стороны, получившей право хода.

Максимум пять карт в руке. Если перед добором их уже пять, новая верхняя карта сразу уходит в открытый сброс. Выбора, какую из старых карт заменить, нет. Карта считается вытянутой: колода уменьшается, её тип видят оба игрока, размер руки остаётся равным пяти.

При пустой колоде попытка добора ничего не даёт. Сброс не восстанавливается, штрафа за исчерпание нет. У каждой стороны колода исчерпывается независимо. Уже законченная партия не продолжает добор.

### 3.4 Мат и ближайшая раздача

Новая карта может спасти от позиции, которая была бы матом без неё, только если добор действительно положен на этой границе. Например, после третьего хода чёрных (C = 6) белые сначала получают положенную карту, затем проверяются их ответы.

Если чёрные получают мат после третьего хода белых (C = 5), нельзя ожидать будущего окончания раунда ради раздачи. Партия заканчивается на текущей границе: её C = 6 никогда не наступает.

Это сознательный календарь общей выдачи v0.1. Его влияние на преимущество первого хода относится к проверке баланса.

## 4. Открытая и скрытая информация

Игрок видит собственную руку, всю доску, активные эффекты и точные сроки, число карт в чужой руке, размеры обеих колод и открытый сброс обеих сторон. Типы карт в чужой руке и порядок будущих карт скрыты.

Сыгранная карта раскрывается при принятии всей команды сервером. Цели, результат и срок её эффектов открыты. Отменённый локальный предпросмотр карты не отправляется сопернику как игровое событие. Автоматический сброс переполнения раскрывается обоим.

Наличие или отсутствие законного ответа, включая итог мата, определяет сервер. Клиент не получает чужую руку, чтобы вычислить это самостоятельно. Обычный зритель получает только открытую проекцию. После окончания партии полная запись доступна её участникам; публичный экспорт по умолчанию остаётся открытой проекцией.

## 5. Атомарная команда и порядок разрешения

### 5.1 Полнота команды

Команда содержит существующий экземпляр карты из руки игрока, все цели карты, обязательное перемещение при необходимости и выборы превращения своих выживших пешек. Для обычного хода без карты передаётся обычная команда. Чужие пешки при принудительном превращении автоматически становятся ферзями.

Обычную карту нельзя сыграть отдельной половиной хода, дождаться реакции или добора, а затем выбрать перемещение. Клиент может подготовить предпросмотр, но сервер принимает карту и ход вместе. При незаконности любой части не расходуются карта, ход, права или случайность, и доска не меняется.

### 5.2 Последовательность

| Шаг | Что происходит |
|---:|---|
| 1 | Проверить матч, ревизию, очередь хода, отсутствие результата и принадлежность карты руке. |
| 2 | На копии состояния проверить цели и применить карту. У обычной карты затем выполнить обязательное перемещение; у остальных перемещения дополнительно нет. |
| 3 | Разрешить фактическое взятие, включая en passant и последствие «Долга крови». Карточные перестановки сами по себе не берут фигур. |
| 4 | Превратить все выжившие пешки, достигшие своего последнего ряда; обновить исторические права. |
| 5 | Проверить геометрию королевского перемещения и рокировки, запрет соседства королей, ограничения приземления и необходимые инварианты. |
| 6 | Завершить целый ход: увеличить C ровно на один, армировать новые эффекты, погасить истёкшие старые эффекты, обновить en passant и счётчик тихих ходов. |
| 7 | Проверить безопасность короля ходившей стороны после всех обязательных окончаний. Нельзя закончить ход, если разморозка в этой же границе оставляет своего короля под шахом. |
| 8 | Если проверка успешна, зафиксировать расход карты в открытый сброс и все изменения одним событием; передать очередь сопернику. |
| 9 | Если C кратно шести, выполнить положенный добор обеим сторонам и открытый сброс переполнения. |
| 10 | Зарегистрировать новую устойчивую позицию один раз и проверить мат, пат и ничьи по общим правилам. Мат имеет приоритет над автоматической ничьёй по счётчику тихих ходов. |

Пункты до фиксации работают на копии состояния. Подсчёт возможных ответов не выполняет реальный добор, не расходует карты и не дописывает повторения.

Между картой и обязательным движением результат партии не объявляется. Начав ход под шахом, игрок должен устранить его всей разрешённой командой. Для составных карточных перестановок проверяется одновременный итог; анимация не превращает их в последовательность самостоятельных ходов. При обычном движении короля и рокировке сохраняются их специальные ограничения на атакуемые клетки.

## 6. Семь карт

### 6.1 Карантин

**Цель:** одна клетка, пустая непосредственно перед применением карты. Затрагивает только фигуры соперника владельца карты. После создания запрета владелец делает обязательный обычный ход любой своей доступной фигурой.

**Эффект:** до окончания двух ближайших ходов затронутой стороны её фигурам запрещено приземляться на выбранную клетку. Любой игрок обязан соблюдать это ограничение, когда принудительно переносит затронутую фигуру карточной перестановкой. Уже стоящую фигуру карта не выбирает и не выталкивает.

**Длительность:** отметить два ещё не завершённых хода затронутой стороны. После каждого такого хода уменьшить счётчик на один; после второго убрать запрет. Пример: белые сыграли карту и закончили ход при C = 1. Она действует на ходах чёрных, заканчивающихся при C = 2 и C = 4, и исчезает в конце C = 4.

**Прохождение и атаки:** пустую запрещённую клетку можно пересечь лучом; пешка может пройти её промежуточной клеткой законного двойного шага. En passant определяется клеткой приземления берущей пешки, а не клеткой снимаемой жертвы. При рокировке оба конечных положения, короля и ладьи, должны быть разрешены; сам транзит через запрещённую пустую клетку не является приземлением.

Карантин **не изменяет геометрическую карту атак**. Король не получает убежища на клетке, которую противник геометрически атакует, даже если его реальное приземление сейчас запрещено. Это явное цифровое решение v0.1: как и для связанной фигуры, контроль поля шире набора разрешённых движений. Обучение обязано объяснить его отдельно. Короли всегда сохраняют угрозы соседних клеток.

Повторный Карантин может продлить запрет отдельным источником. Запреты разных владельцев на одной пустой клетке могут действовать одновременно, тогда на неё не приземляется ни одна сторона. Они не перекрывают лучи и имеют независимые сроки.

### 6.2 Задний ход

**Цель:** одна своя незамороженная пешка. Карта должна сопровождаться именно её обратным ходом.

Для этого перемещения направление пешки меняется на противоположное: один шаг прямо назад на пустую клетку либо взятие на одной из двух задних диагоналей. Двойного обратного шага и обратного en passant нет. Обычный ход другой фигурой или этой пешкой вперёд после данной карты не допускается.

Это разрешение конкретного движения, а не постоянное изменение владельца, типа или направления. До и после команды пешка контролирует обычные передние диагонали. Карта в руке не создаёт угрозы обратного взятия короля; королей физически брать нельзя. После завершения обратного движения шах определяется обычной геометрией новой позиции.

Любой фактический обратный ход снимает историческое право начального двойного шага и сбрасывает счётчик тихих ходов. Белая пешка не может попасть таким ходом на первую горизонталь, чёрная — на восьмую: неповышающий край запрещён общей политикой v0.1. Запреты приземления и побочное удаление по «Долгу крови» применяются обычно.

### 6.3 Криостаз

**Цель:** одна чужая фигура, кроме короля. Карта занимает весь ход.

Фигура заморожена до конца ближайшего хода своего владельца. Она не может совершать обычное перемещение, взятие, en passant или участвовать ладьёй в рокировке; не создаёт геометрических угроз. На доске остаётся и блокирует лучи. Замороженную фигуру можно взять.

Заморозка привязана к ID. Её разрешается принудительно перемещать «Тектоникой» или «Перестановкой судеб»; срок не обновляется и состояние не исчезает. Превращение сохраняет заморозку на новом типе той же фигуры.

После окончания ближайшего хода владельца эффект снимается, в том числе если владелец вместо движения сыграл собственную карту. С этого момента фигура снова создаёт угрозы. Если снятие заморозки делает короля ходившей стороны небезопасным, вся выбранная команда была незаконной.

### 6.4 Ледниковый фронт

**Цель:** одна горизонталь или вертикаль, на которой есть хотя бы одна фигура, кроме короля. Карта занимает весь ход.

В момент активации запомнить ID всех некоролевских фигур на этой линии обеих сторон и заморозить их по правилам Криостаза. Короли остаются активными. Новая фигура, вошедшая позднее на линию, не замораживается; перенесённая с линии фигура сохраняет своё состояние.

**Срок:** два полных хода игроков после хода активации — по одному будущему ходу каждой стороны. Если карта сыграна на ходе, заканчивающемся при C = k, эффект исчезает в конце C = k + 2. Например, после белого C = 1 фигуры заморожены на чёрном C = 2 и белом C = 3, затем оттаивают.

Это даёт собственным замороженным фигурам настоящий будущий ход ограничения, поскольку сам ход активации уже потрачен на карту. Порядок белых и чёрных не меняет длительность в последующих действиях.

### 6.5 Долг крови

**Цель:** одна своя фигура, кроме короля. Карта занимает весь ход. Метка открыта обоим игрокам, привязана к ID и сохраняется при перемещении, заморозке и превращении.

Если помеченную фигуру фактически берёт чужая фигура, кроме короля, взявшая тоже немедленно удаляется с доски. Сначала снимается жертва и выполняется взятие, затем удаляется взявшая. В случае en passant метка проверяется на реальной снимаемой пешке.

Король может законно взять помеченную фигуру без самоуничтожения; его итоговая безопасность всё равно обязательна. Карта никогда не удаляет короля как побочный эффект.

Удаление атакующего — эффект, **не новое взятие**. Оно не запускает следующий Долг крови и не создаёт цепь. Если обе фигуры помечены, погибают они обе, а метка атакующего просто исчезает вместе с ним. Несколько меток на жертве удаляют атакующего только один раз.

Если атакующая пешка погибла от Долга крови, она не превращается даже при взятии на последней горизонтали. Если удаление атакующего открывает удар на собственного короля, исходное взятие незаконно.

**Срок:** два последующих завершённых хода после активации, как у Ледникового фронта. Метка исчезает в конце C = k + 2 или раньше вместе с фигурой. Это охватывает ближайший ответ соперника и следующий ход владельца карты.

### 6.6 Тектоника

**Цель:** одна непустая горизонталь и направление на одну клетку влево или вправо. Карта занимает весь ход.

Все находящиеся на этой горизонтали фигуры обеих сторон, включая королей и замороженных, одновременно смещаются на одну клетку. Пустоты смещаются вместе с расстановкой; соседняя фигура не мешает, если сама уходит в том же общем перемещении. Это перестановка, а не серия толчков или взятий.

Если хоть одна фигура выйдет за край, карта незаконна. Пропускать крайних, удалять их, выбирать только удобные фигуры или переносить через противоположный край нельзя. Карантин проверяется для каждой конечной клетки с учётом владельца перемещаемой фигуры.

После одновременного сдвига свой король должен быть в безопасности, короли не могут соседствовать. Чужому королю можно дать шах. Королевская безопасность оценивается в итоговой позиции; карточное перемещение не является рокировкой.

Каждый фактический перенос обновляет историю движения. Перенесённый король или исходная ладья теряют соответствующие права рокировки; перенесённая пешка — право начального двойного шага. Перемещение уязвимой пешки отменяет её en passant. Заморозки и метки переносятся по ID.

### 6.7 Перестановка судеб

**Цель:** две разные фигуры, кроме королей, на разных клетках. Разрешены любые сочетания владельцев. Карта занимает весь ход.

Фигуры одновременно меняются клетками. Тип, владелец и ID сохраняются; ни одна не взята. Расстояние, лучи и промежуточные заслоны не ограничивают эту карту. Замороженные фигуры участвуют и остаются замороженными.

Для обеих конечных клеток действуют Карантин и общая политика крайних горизонталей пешки. Любой пешке запрещено попасть на свой неповышающий край. Достигшая собственного ряда превращения своя пешка превращается по выбору игрока из Q/R/B/N, включённому в команду; чужая автоматически превращается в ферзя. Превращение разрешается до окончательной проверки безопасности короля.

Обе фигуры считаются двигавшимися для исторических прав, даже если позже вернутся обратно. После перестановки король ходившей стороны обязан быть безопасен; шах чужому королю допустим.

## 7. Сроки, наложения и исчезновение состояний

| Эффект | На что привязан | Срок после хода активации |
|---|---|---|
| Карантин | Клетка и затронутая сторона | Два ближайших завершённых хода затронутой стороны |
| Задний ход | Конкретная пешка и текущая команда | Только обязательное обратное движение; постоянного состояния нет |
| Криостаз | ID чужой фигуры | До конца ближайшего хода владельца фигуры |
| Ледниковый фронт | Зафиксированный набор ID | Два последующих завершённых хода игроков |
| Долг крови | ID своей фигуры | Два последующих завершённых хода игроков |
| Тектоника, Перестановка судеб | Одновременное изменение клеток | Мгновенно, без временного эффекта |

При завершении хода сначала истекают положенные старые источники, затем строится итоговая активность всех оставшихся источников. Новый источник армируется с текущим C и не теряет длительность из-за собственного хода активации. Удаление и истечение обрабатываются без повторного рекурсивного прохода эффектов.

Каждый источник хранится отдельно. Фигура заморожена, пока действует хотя бы один источник заморозки; их сила не складывается. Повторное наложение на уже замороженную или помеченную фигуру разрешено: оно расходует карту и ход и создаёт новый срок, даже если сейчас не меняет функциональное состояние. Нельзя получать дополнительные действия за наложение.

Снятая фигура теряет все привязанные к ней состояния. Источник-карта остаётся в сбросе. У состояний нет аур: снятие другой фигуры, уход с линии или исчезновение владельца исходной карты не меняет их срок. Владельцы фигур в этой игре никогда не меняются.

## 8. Особые шахматные случаи

### 8.1 Пешки и исторические права

Любое фактическое движение пешки, добровольное или принудительное, окончательно снимает право начального двойного шага. Возврат на исходную клетку, разморозка, карточный обмен и превращение его не восстанавливают.

Своя пешка, принудительно достигшая ряда превращения, требует выбора в принятой команде; чужая становится ферзём автоматически. Выборы относятся ко всем выжившим пешкам после удалений. Неповышающий край для пешки запрещён, поэтому белая пешка не остаётся на первой горизонтали, чёрная — на восьмой. Превращение сохраняет ID и все неистёкшие состояния.

### 8.2 En passant

Обычное право действует ровно в ближайший ход соперника. Карта вместо движения тоже расходует этот ход и закрывает окно. Карантин, сыгранный перед допустимым en passant, сам по себе окно не закрывает.

Замороженная пешка не может выполнять en passant; замороженную уязвимую пешку можно взять при остальных выполненных условиях. Вынужденный перенос уязвимой пешки прекращает её уязвимость немедленно. Задний ход не создаёт обратного en passant. Долг крови проверяет состояние жертвы на её фактической клетке.

### 8.3 Рокировка

Обычные исторические права и королевский путь сохраняются. Замороженная ладья не может рокировать. Метка Долга крови сама по себе рокировке не мешает. Король не может пройти через геометрически атакуемое поле, даже если атакующему мешает Карантин; замороженные фигуры угроз не создают.

Конечные клетки короля и ладьи проверяются на запреты приземления. Принудительно передвинутый король или исходная ладья окончательно теряют соответствующее право. Ни возвращение, ни карточный обмен не восстанавливают его.

### 8.4 Принудительные перемещения

Тектоника и Перестановка действуют на замороженных и связанных фигур, но обязаны завершиться безопасностью собственного короля. Они не подчиняются геометрии перемещаемой фигуры. Отдельно действуют ограничения самой карты, крайних рядов пешек и Карантина.

Перемещение противника не даёт взятия, очков или отдельного хода этому противнику. Превращение чужой пешки не открывает окно выбора второму игроку: применяется автоферзь.

## 9. Шах, мат, пат и ничьи

### 9.1 Карта угроз

Использовать обычную геометрию, владельцев и реальные препятствия. Связанные фигуры продолжают геометрически атаковать; не вызывать генератор законных ходов, чтобы определить атаки. Замороженные некоролевские фигуры не атакуют. Карантин и карты в руке не меняют геометрические атаки. Короли всегда контролируют соседние клетки.

Задний ход меняет разрешённое движение конкретной команды, а не постоянную карту угроз пешки. Долг крови не выключает угрозы помеченной фигуры. Изменения клеток, превращения, побочные удаления и разморозки меняют карту угроз обычным пересчётом.

### 9.2 Полный набор ответов

Сервер обязан перебрать обычные ходы, допустимые пары «обычная карта + движение», редкие карточные ходы, эпические и легендарные перестановки, включая нужные выборы превращения. Проверка безопасности включает окончание сроков на предполагаемой границе.

«Мат стандартного шахматного движка» не является достаточным основанием завершить Джокер: Криостаз, Перестановка или другая доступная карта может дать законный ответ. Напротив, если подходящая карта осталась в колоде, но сейчас добор не положен, это не спасение.

Мат — текущий шах и отсутствие любой законной полной команды. Пат — отсутствие такой команды без текущего шаха. Если король сейчас не под шахом, но все попытки хода оставили бы его под ударом после обязательного истечения эффектов, это пат, а не прогнозируемый мат.

Проверки допустимости запускают только преобразование состояния и проверку безопасности. Они не вызывают заново определение мата и не меняют настоящую историю, руки или счётчики.

### 9.3 Повторение позиции

Применяются заявление на третьем и автоматическая ничья на пятом повторении, но сравнивается полное значимое состояние Джокера, а не только расстановка.

Ключ включает сторону хода; клетки, владельцев и типы фигур; значимые исторические права; en passant; активные заморозки и метки с нормализованными остатками срока; карантинные клетки и затронутые стороны; состав обеих рук по типам; оставшийся порядок типов в обеих колодах; количества типов в сбросах; расстояние до очередной раздачи. Абсолютный C заменяется этими относительными сроками. Если обе колоды навсегда пусты, фаза будущего добора больше не входит в ключ.

Право en passant различает позиции только при наличии законной полной команды, выполняющей это взятие. Допускается конечная проверка кандидатной команды с разрешением обязательных эффектов, без регистрации повторений и без определения мата. Само наличие записи об уязвимой пешке при отсутствии допустимого взятия не различает позиции.

ID взаимозаменяемых экземпляров карты и порядок открытого сброса не различают позиции. ID фигур используются для разрешения привязок, но произвольная замена ID двух полностью эквивалентных фигур не создаёт новую игровую позицию. Нельзя игнорировать реальные отличия исторических прав или состояний. Неиспользуемое после стартового перемешивания состояние генератора не входит в ключ: очередь будущих типов уже задаёт все будущие доборы. quietPly и счётчики появлений позиции также не входят в ключ, но сохраняются отдельно для оценки результата и поиска.

Скрытые руки и очереди учитывает сервер. Клиент получает право заявить ничью и результат, а не чужие скрытые данные. Регистрация происходит только один раз на устойчивой границе после положенного добора. Отмена тренировочного хода восстанавливает старый счётчик, повтор не дописывает дубликат.

### 9.4 Тихие ходы и материал

Счётчик увеличивается один раз за целый ход. Сбрасывается при фактическом движении пешки, включая принудительное, или при безвозвратном удалении фигуры, включая Долг крови. Игра карты, добор, сброс, заморозка и истечение сами по себе его не сбрасывают.

Применяются 100 и 150 ходов игроков для правил 50 и 75 ходов соответственно. Мат имеет приоритет над автоматическим лимитом. Автоматическое заключение о недостаточном материале в v0.1 применяется только к голым королям; другие обычные таблицы недостаточного материала для Джокера не доказаны и не используются.

## 10. Сеть, воспроизведение и информация ИИ

- Полный state, порядок колод и скрытые руки авторитетно хранятся на сервере. Клиент не присылает «выпавшую карту», содержание колоды или итог перестановки.
- Команда включает match ID, ruleset ID, ожидаемую ревизию и уникальный command ID. Повтор уже принятого ID возвращает прежний результат и не расходует вторую карту или добор. Устаревшая ревизия отклоняется без частичного применения.
- Проверять реальный ID экземпляра в руке отправителя. Подмена типа, владельца, произвольный выбор чужого превращения и вторая карта в команде отвергаются.
- Журнал хранит полную принятую команду, исходы доборов, фактические цели, удаления, превращения, сроки и расход карты. Публичная проекция журнала скрывает типы нераскрытых карт и очереди колод; её контрольная сумма не содержит секреты полного состояния.
- Переподключение возвращает игроку его руку, открытую доску, сроки и текущую ревизию, но не скрытые данные соперника. Несколько анимаций одного хода не создают несколько игровых границ.
- Тренировочная отмена восстанавливает обе очереди, руки, сброс, сроки, текущую ветвь истории, повторения и счётчик тихих ходов. Повтор той же ветви не даёт новую случайную карту. Рейтинговая игра не разрешает отмену.
- Обычные FEN/PGN недостаточны для полной партии. Экспорт имеет версию ruleset и явные карточные события; импорт проверяет сохранность 25 исходных экземпляров каждой стороны по их зонам, права, сроки, фазу, королей и пешечные инварианты.
- ИИ получает собственную руку и публичную информацию. Ему не передаются истинная рука соперника, будущая очередь карт, seed или полное серверное дерево случайности. Поиск вправе моделировать возможные скрытые состояния по известному составу и раскрытым картам, но не читать настоящий скрытый state.
- Уровни и приблизительные Elo будут задачей отдельной итерации реализации и калибровки. Этот документ не подтверждает существование адаптированного движка или его измеренной силы.

## 11. Обязательные объяснения игроку

В обычном режиме игрок должен видеть сторону хода, цену карты в действиях, свои карты, числа скрытых карт соперника, оставшиеся колоды и точное окончание каждого эффекта. Например: «Снимется после следующего хода чёрных», а не неоднозначное «ещё один ход».

Учебник и интерактивное обучение должны раздельно разобрать:

1. Обычную карту с обязательным ходом и карту, занимающую весь ход.
2. Каждую из семи карт на короткой позиции, включая неудобное для себя применение общей заморозки или сдвига.
3. Карантин: запрет приземления, прохождение лучей и сохранение геометрических угроз королю.
4. Заморозку: отсутствие атак, сохранение блока, перенос состояния вместе с принудительно перемещённой фигурой.
5. Точные сроки Криостаза и общего Ледникового фронта, включая будущее ограничение собственных фигур.
6. Долг крови, исключение короля и отсутствие цепной реакции от побочного удаления.
7. Одновременность Тектоники и Перестановки, утрату исторических прав и вынужденное превращение.
8. Защиту от кажущегося мата картой и добор только по настоящему календарю.
9. Переполнение руки, открытый сброс и исчерпание колоды.

Заморозка и метки не должны скрывать цвет армии. Карантин должен показывать, какой стороне запрещено поле. На руке противника показываются рубашки, не случайно восстановленные превью карт. Тематические 3D-модели, эффекты и звук выбираются отдельно до реализации; они не меняют эти правила.

## 12. Сценарии для обязательной проверки следующей итерации

Это ожидаемые результаты правил, а не отчёт о запущенных тестах.

| Группа | Сценарий | Ожидаемый результат |
|---|---|---|
| Команда | Обычная карта без требуемого движения | Отклонена, карта и ход сохранены |
| Команда | Законная карта, но незаконное финальное перемещение | Вся команда отклонена без частичных изменений |
| Команда | Повтор принятого command ID | Возвращён тот же результат, один расход |
| Карантин | Луч проходит через пустую запрещённую клетку | Разрешён |
| Карантин | Король хочет встать на поле под геометрическим ударом, ссылаясь на запрет противнику | Ход незаконен |
| Карантин | Принудительная перестановка отправляет затронутую фигуру на запрещённое поле | Вся карта незаконна |
| Карантин | Запрещена только промежуточная клетка двойного шага пешки | Сам запрет проходу не мешает |
| Задний ход | Попытка обратного двойного шага или en passant | Отклонена |
| Задний ход | Белая пешка отступает на первую горизонталь | Отклонена |
| Заморозка | Замороженный слон на линии дальней ладьи | Сам слон не атакует, но продолжает блокировать ладью |
| Заморозка | Замороженная фигура переставлена картой | Новый квадрат, прежний ID и срок |
| Заморозка | Истёк один из двух источников | Фигура остаётся замороженной до окончания второго |
| Заморозка | В конце предполагаемого хода разморозка открыла шах своему королю | Полная команда незаконна |
| Фронт | Фигура позднее вошла на выбранную линию | Она не заморожена этим старым источником |
| Долг крови | Помеченную фигуру берёт король | Король не удаляется; проверяется его обычная безопасность |
| Долг крови | Обе участвующие фигуры помечены | Обе удалены один раз; цепи нет |
| Долг крови | Берущая пешка дошла до превращения, но погибает от метки | Пешка удалена, превращения нет |
| Тектоника | Крайняя клетка в направлении сдвига занята | Карта отклонена без удаления фигур |
| Тектоника | Соседние фигуры одного ряда одновременно сдвигаются | Разрешено при остальных выполненных условиях |
| Права | Карта подвинула исходную ладью, затем другая вернула её | Рокировка с ней не восстановлена |
| Превращение | Карта доставила чужую пешку на её ряд превращения | Автоматический ферзь до проверки короля |
| En passant | Вместо немедленного ответа сыграна карта за весь ход | Окно закрыто |
| Добор | C = 6, новая карта даёт единственный защитный ход | Мат не объявлен, карта доступна |
| Добор | C = 5, законного ответа нет, карта могла бы прийти позже | Партия заканчивается сейчас |
| Добор | Рука полна, приходит легендарная карта | Открытый сброс новой карты, рука не меняется |
| Добор | Колода пуста | Нет карты, штрафа или перетасовки |
| Повторения | Доска совпадает, рука или порядок будущей колоды отличается | Позиции различны |
| Повторения | Всё значимое совпало, отличаются только ID одинаковых карт | Позиции эквивалентны |
| ИИ | У сервера известен следующий добор противника | Он не входит в наблюдение ИИ |

## 13. Что проверять в балансе после аудита правил

Числа и состав v0.1 выбраны для определённой спецификации, а не подтверждены практикой. Отдельно проверить преимущество стороны при общей раздаче после хода чёрных, силу бесплатного Карантина вместе с движением, частоту заморозок, ценность карточного хода под шахом, влияние Долга крови на размены, глобальную дальность Перестановки, количество обычных обратных ходов в колоде и потери карт при полной руке.

Следующий агент должен сначала проверить полноту и согласованность этих правил с COMMON_RULES.md, уточнить редакционные объяснения и воспроизводимые позиции. Изменение параметров по результатам баланса оформляется новой версией ruleset и отдельным описанием причин. Этот черновик не означает, что баланс, реализация, сеть, ИИ, ассеты или локальная приёмка уже выполнены.
