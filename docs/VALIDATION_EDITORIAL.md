# REMORSE — редакторская приёмка на Mac

24 ноября 2026 года. Исходная доработка в `origin/main` — `a23f503e220ce5c4f68e2d6c679c0e2255674c72`. Игровой код — `eed25067f6cbb684600a06723ba60756f3be0521`. Вход production — `index-BvxKjPfx.js`. [Редакторский аудит](TUTORIAL_EDITORIAL_AUDIT.md) · [Предыдущая поставка](VALIDATION_TUTORIAL.md)

## Исправления

- При смене уроков RU/EN прямо называют новую позицию. Карточка счётчика показывает точное количество оставшихся ходов игроков и объясняет округление на значке фигуры. Вступление уточняет условие бонусного действия, а отдельная подсказка в уроке предлагает завершить ход.
- Результат последнего упражнения называет сторону хода, условие и срок исцеления либо срок исчезновения. Объяснение и кнопка завершения помещаются при 568×320.
- В портретном режиме место для карточки фигуры резервируется заранее. Подсвеченная клетка остаётся на месте при выборе фигуры. На низких экранах результат кубика, бонусное действие и оба срока видны одновременно.

## Живая приёмка

Отдельный агент **`gpt-6.1-terra` / `high`** прошёл все девять русских уроков мышью в установленном Chrome 158.0.8127.37 с 3D-доской при 1280×800. Первый проход шёл по интерфейсу из чистого профиля. В конце приёмщик подвёл слона к коню и продолжил позицию в тренировке против Remorse Engine 4/10. Дополнительно он посмотрел первый урок на английском при 360×800 и 568×320. После редакторских правок проверил переход к новой позиции, оба результата финального хода, видимость кнопки при 568×320 и открытие настройки через «Новая партия».

На следующих кандидатах Terra повторила реальный ход касаниями e2→e4 в 3D при 390×844 и подтвердила неподвижность доски при открытии карточки. На финальном кандидате она сыграла взятие с броском 6 на 2D-доске при 360×800 и 568×320. Значение кубика, кнопка завершения и сроки 6 и 2 были видимы вместе. После нажатия сроки стали 5 и 1, ход перешёл к чёрным. Окна Terra и дополнительные проверки Chrome работали с отключённым выводом звука и изолированными настройками.

## Сборка и тесты

```sh
npm ci
npm run check
npm run build -- --outDir .qa/editorial-checked
npm run preview -- --host 127.0.0.1 --port 4181 --strictPort --outDir .qa/editorial-checked
# В отдельном терминале
REMORSE_TEST_PORT=4181 npm run test:e2e -- --workers=2 --output=.qa/editorial-checked-e2e
```

Node 26.3.0, npm 11.16.0, Playwright 1.65.1. TypeScript, ESLint и **230 модульных тестов в 14 файлах** прошли. В полном прогоне production-кандидата **88 браузерных тестов прошли** в Chromium 159.0.8154.6 и WebKit 27.2. Повторная сборка из игрового коммита совпала с проверенной папкой побайтово.

## Активация

На [127.0.0.1:4173](http://127.0.0.1:4173/) и на [Wi-Fi адресе Mac](http://192.168.31.44:4173/) HTML и входной JS совпадают с проверенной production-сборкой. В изолированном Chrome оба адреса открыли первый урок с рабочей 3D-доской. В подключённом Chrome оставлена вкладка с `index-BvxKjPfx.js`. В ней восстановилась ранее сохранённая тренировка с русским интерфейсом, выбранным 2D и выключенным звуком.
