# Chess 2 — актуальный выбор игр

**Единый актуальный выбор владельца от 25.11.2026: [docs/ideas/SHORTLIST.md](ideas/SHORTLIST.md).**
Документы и статусы: [docs/ideas/README.md](ideas/README.md).

**Утверждённая очередь: 1 — COLOSSUS / Колосс, 2 — WILDCARD / Джокер.** Порядок остальных игр владелец определит позже.

Всего выбрано девять уникальных направлений. Кроме первых двух, сохраняются **OVERDRIVE / Форсаж, CHORUS / Хор, CHIMERA / Химера, SIGNAL / Связь, UMBRA / Изнанка, PARADOX / Парадокс, SYNCHRO / Синхрон**, без внутреннего ранжирования. Это выбор для будущей реализации, а не подтверждение завершённых правил или баланса. Уже разработанные части Форсажа сохраняются.

- WILDCARD получает [две колоды](ideas/WILDCARD_TABLE_DECK.md): раздаточную для личных рук и событийную для стола. **Эффект «Орбита» сохраняется как карта стола внутри Джокера; отдельная игра ORBIT удалена.**
- CHIMERA имеет [один канонический документ](chess-2/CHIMERA_RULES.md); второй прежний файл является указателем.
- COLOSSUS зафиксирован в [новой пользовательской редакции](ideas/06_COLOSSUS.md): HP фигур, броня и HP босса, разные боссы, защита короля и карты.
- Для COLOSSUS подготовлен [полный проект правил v0.1](chess-2/COLOSSUS_RULES.md) с [арифметической проверкой стартовых чисел](ideas/COLOSSUS_BALANCE_V0_1.md). Это предложение ChatGPT от 26.11.2026 по запросу владельца; полные партии и готовый продукт этой записью не подтверждаются.
- **REMORSE готова по сообщению владельца и убрана из очереди будущей реализации.**
- RELAY / Эстафета сохраняет прежний статус исключения. Последние удаления идей записаны в SHORTLIST.md; исключённые досье больше не входят в актуальный каталог.
