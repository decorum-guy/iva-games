# OVERDRIVE / Engine SDK — состояние итерации

25 ноября 2026 года. Ветка `feat/overdrive-sdk`, исходный main — `84b81ba06ba736fc3c571311baeaced7ec57a71a`. **Реализация и доступные программные/серверные проверки завершены; визуальная и слуховая приёмка ещё не выполнена.** Полный протокол — [VALIDATION.md](VALIDATION.md).

## Что реализовано

- Общий SDK поиска и настоящий адаптер REMORSE; отдельный адаптер Форсажа с десятью профилями.
- Полное ядро `overdrive-v1`: обычные шахматы, энергия, шесть приёмов, формы, усиленные угрозы, принудительные превращения, исторические права, ничьи и завершение.
- Собственный 3D/2D-интерфейс RU/EN, шесть оригинальных GLB, 18 готовых оригинальных WAV, локальные шрифты с лицензиями. Общий план времени для движения и звука.
- Тренировка, локальная игра вдвоём, девять интерактивных уроков, сохранение, выбор превращения и составных действий, клавиатура, mute/громкость и reduced motion.
- Авторитетные гостевые сетевые комнаты, приглашения, готовность, восстановление после обрыва/перезапуска, ничья, сдача и реванш. Свои протокол, cookie и SQLite.

## Фактически выполнено

- `npm run check`: TypeScript, ESLint, **679 тестов / 46 файлов** — успешно.
- `npm run build`: клиент с двумя входами и Node-сервер — успешно.
- `npm run overdrive:smoke`: **36 проверок собранного сервера**, реального HTTP/WebSocket, ресурсов и перезапуска — успешно.
- Восемь реальных партий ИИ, 618 принятых действий с точным повтором: семь матов и одна остановка по пределу проверки. После исправления оценки окончания точное остановленное состояние доведено до мата за 11 дополнительных полуходов.
- Программная отрисовка и осмотр геометрии шести настоящих GLB; проверка SHA, шрифтов и декодирования всех 18 WAV. Это не просмотр приложения и не прослушивание.

Документальная ветка `design/chess-2-concepts` проверялась повторно во время разработки и перед фиксацией. Последний принятый снимок — `6a7ceed2b039bc644cffe7506d955a2778d47bc3`; пять вариантов сохранены в `docs/chess-2`. Более новый статус REMORSE из main сохранён.

## Незакрытая приёмка

Standalone Chromium остановился до загрузки страницы: окружение запретило создание Unix socket. Подключённый браузер недоступен без исходного extension context. Облачный браузер не видит loopback-сервер этой рабочей среды; инспекция его страницы ошибки запрещена политикой инструмента. Повторных обходных попыток не предпринималось.

Поэтому **Playwright-сценарии написаны и обнаружены, но не исполнены**. Не подтверждены WebGL-вид приложения, работа реального браузерного Worker/AudioContext, полный UI-проход двух игроков, слышимый микс, FPS и физические телефоны. Следующий конкретный шаг — исполнить `npm run overdrive:e2e` и визуальную/слуховую приёмку в разрешённом локальном браузере; исправлять только выявленные дефекты. Готовность исходников не заменяет этот этап.

Визуальные требования и оставшиеся проверки перечислены в [VALIDATION.md](VALIDATION.md). До их выполнения ветка остаётся кандидатом на приёмку. Публичной публикации, активации на Mac, изменения DNS или человеческой калибровки Elo в этой итерации не было. Ротация пешки на последнюю горизонталь остаётся явно отмеченным предметом дальнейшей балансировки.
