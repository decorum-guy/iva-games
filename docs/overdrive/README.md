# Форсаж / OVERDRIVE

Самостоятельная игра Chess 2: обычная шахматная основа, два общих накопителя по пять делений и шесть позиционных приёмов. Взятие приносит +1, новый награждаемый шах +2. Пять оплачивают один приём, десять включают форму выбранной фигуры на три собственных хода, включая ход включения.

Исходники и ресурсы находятся в самостоятельном workspace `games/overdrive` (`@chess-2/overdrive`); общий поиск импортируется из `@chess-2/engine-sdk`. Правила и художественная система принадлежат этой игре. [Структура монорепозитория](../MONOREPO.md) и [задание локальному агенту](../../prompts/ACCEPT_OVERDRIVE_MONOREPO.md) описывают текущую приёмку.

## Запуск

В изолированной рабочей копии актуальной ветки `feat/overdrive-sdk`, **из корня репозитория**:

```sh
npm ci
npm run build
PORT=4185 HOST=127.0.0.1 DATABASE_PATH=./data/preview-remorse.sqlite OVERDRIVE_DATABASE_PATH=./data/preview-overdrive.sqlite npm start
```

Открыть `http://127.0.0.1:4185/overdrive/`. REMORSE остаётся на `/`. Порт 4185 позволяет не занимать действующий 4173; новые базы не затрагивают личные партии владельца. Команды предполагают обычный локальный запуск без унаследованного `NODE_ENV=production`; для production обязателен `PUBLIC_ORIGIN` согласно серверной инструкции.

Для телефона в своей сети можно выбрать `HOST=0.0.0.0` и открыть LAN-адрес компьютера с тем же портом и `/overdrive/`. Это инструкция, а не подтверждение проверки физического телефона. Для двух игроков нужны независимые браузерные профили или устройства; одна вкладка с тем же cookie является тем же гостем.

`npm start` обслуживает обе страницы, HTTP API и WebSocket. Статический Vite preview поддерживает локальные режимы, но сам не запускает комнаты.

Отдельный клиент можно собрать командой `npm run build:overdrive` либо `npm run build --workspace @chess-2/overdrive`; выход — `games/overdrive/dist`. Общая команда `npm run build` сохраняет `/overdrive/` вместе с REMORSE. Отдельный выход содержит корневой `index.html` и требует соответствующего статического сервера; для комнат нужен полноценный HTTP/WebSocket-сервис. Ни одна из этих команд сама не размещает игру в интернете.

## Режимы и интерфейс

- Тренировка с настоящим Worker-движком и десятью бюджетами сложности. Подписи ≈400–2200 относятся к предварительной внутренней шкале Форсажа.
- Два игрока за одной доской: обычные и усиленные действия, отмена хода и сдача.
- Гостевые сетевые комнаты: приглашение, готовность, общий авторитетный сервер, восстановление, ничья, сдача и реванш со сменой сторон.
- Девять интерактивных упражнений на общей версии правил; подтверждение и перезагрузка, затем продолжение учебной позиции либо обычная партия.
- Русский/английский, собственные 3D-модели и 2D-силуэты, выбор превращения и составной цели, клавиатура, reduced motion, отдельные звук и громкость.

Выберите фигуру и режим: ход, импульс или форсаж. Затем выберите клетку/цель. Когда одной клетке соответствует несколько полных команд, интерфейс предлагает конкретный вариант. Повторное нажатие на выбранную фигуру или Escape снимает выделение. Клавиатурные стрелки перемещают фокус между клетками, Enter выполняет выбор.
