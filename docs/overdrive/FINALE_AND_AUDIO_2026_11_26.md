# Форсаж — финал с матом и банк звука v2

Локальная [демонстрация игры](http://127.0.0.1:4197/overdrive/) и [позиции для мата и прослушивания](http://127.0.0.1:4198/tests/fixtures/finale.html) работают на разных портах Mac. На новом профиле звук выключен. Основа — `8a7a8c3f4cf6deb9e84e710dcfe99970483d48e2`, ветка `review/overdrive-v2-release`, [PR №9](https://github.com/decorum-guy/iva-games/pull/9).

## Реализация

`c186c9b4ec5446671819c3bd4f2855febe11689b` добавил движение и звук. У короля отдельный шарнир на краю основания. Для восьми направлений офлайн вычислены первые пересечения треугольников поставляемых GLB, край траектории и угол второго касания доски. При выборе направления учитываются фигуры в итоговой позиции, разворот коней и границы поля. Свободное направление имеет приоритет. В тесноте выбирается наибольший допустимый наклон, от контакта слегка качается единственная опорная фигура. На кадре используется готовая траектория с ограничением шага 48 мс. После остановки сохраняется итоговая поза.

Падение начинается на отметке результата общего плана хода. Таймер обычного действия может завершиться, пока король ещё качается. Результат и новая партия доступны с момента подтверждения. Уже завершённая позиция открывается с лежащим или опёршимся королём. При спокойных анимациях поза устанавливается после матующего действия.

`a22cbc34b8abe486388fb412cfd64e98d19990ad` синхронизировал статическую позу при повторном открытии 3D и потерю WebGL-контекста. `0996e7020b297f115d64e68dcd01ebe645a07d47` исключил физический звук под доступной клавиатурной доской и диалогом. `a77e42ba4cceffe0d44db82d7e99f678bba0ff03` сохранил остановленные часы сцены при повторной синхронизации той же сетевой позиции.

## Звук

Банк `overdrive-original-dsp-v2` содержит 20 WAV, 1 169 520 байт, stereo PCM16, 32 кГц. Генератор синтезирует все сигналы из резонансов и фильтрованного шума с фиксированным seed. 14 прежних файлов побайтно сохранены, включая обычный ход, шесть способностей, управление, энергию, форму и завершение партии без мата.

| Событие | Файл | Длина | Изменение |
| --- | --- | ---: | --- |
| Взятие | capture.wav | 290 мс | Плотный двухчастный керамический удар в момент контакта |
| Превращение | promotion.wav | 420 мс | Один созвучный сигнал при смене модели для всех четырёх фигур и принудительного превращения |
| Шах | check.wav | 310 мс | Два коротких резонанса |
| Мат | mate.wav | 570 мс | Спускающиеся тоны с мягкой атакой |
| Касание доски | board-contact.wav | 270 мс | Приглушённый низкий удар |
| Контакт с опорой | piece-contact.wav | 150 мс | Тихий керамический стук |

На взятии с превращением звук новой фигуры приходится на смену модели. Сигналы дохода и полной банки в сочетании с шахом, матом или превращением звучат тише. При мате звучит только один сигнал результата. Видимый первый контакт может озвучиться один раз. Банк проходит проверки заголовков, SHA-256 и отсутствия клиппинга. Повторная генерация таблицы пересечений и всех WAV дала те же файлы.

## Воспроизведение

Из корня этого worktree, для отдельного сервера игры:

```sh
npm ci
npm run build
mkdir -p .qa
PORT=4197 HOST=127.0.0.1 PUBLIC_ORIGIN=http://127.0.0.1:4197 \
DATABASE_PATH=.qa/preview-remorse.sqlite OVERDRIVE_DATABASE_PATH=.qa/preview-overdrive.sqlite \
node dist-server/main.js
```

Во втором терминале запустите локальную страницу позиций. У неё собственная область хранения, сервер слушает loopback. Выбор позиции заменяет тренировочное сохранение на порту 4198.

```sh
npx vite --config games/chess/overdrive/tests/fixtures/vite.config.ts
```

На странице позиций выберите «Мат в углу» и сыграйте ладьёй a6–a8 либо «Опора на соседа» и сыграйте конём h6–f7. Закройте стартовое меню крестиком. Для «Батареи с матом» выберите слона d4, затем «Импульс» и чёрную ладью g7. В позиции «Ферзь с матом» пешка f7 берёт ладью g8 и получает выбор превращения. Там же доступны мат белому королю, принудительное превращение чужой пешки, обычный шах и налёт со взятием. Переключатель «Включить звук» действует на прослушивание отдельных сигналов и следующую выбранную позицию.

## Проверки исполнителя

- `npm run check` — границы пакетов, TypeScript, ESLint и 770 тестов в 57 файлах. 43 теста в трёх целевых наборах проверяют ход, финал и звук.
- `npm run build:all` собрал оба шахматных клиента, сервер, платформу и портал. `npm run overdrive:smoke` выполнил 38 проверок HTTP/WebSocket, файлов банка и восстановления. `npm run platform:smoke` прошёл с двумя независимыми клиентами.
- `OVERDRIVE_TEST_PORT=5199 npm run overdrive:e2e` — 25 успешных сценариев Chromium и WebKit, включая уроки и реальные гостевые комнаты. В конфигурации мобильного и горизонтального проектов пропущены две проверки 3D. Отдельный повтор на исправленном клиенте покрыл 3D/клавиатуру, смену настройки движения и сетевой реванш.
- `node games/chess/overdrive/tests/fixtures/record-finale.mjs` записал четыре игры headless Chromium через реальные клики по canvas. В кадрах свободного падения видны опрокидывание целой модели внутрь поля, основание на исходной клетке и сохранённая красная подсветка. В тесной позиции король опирается на фигуру g7. Также просмотрены финальные кадры после «Батареи» и взятия с превращением. Локальные ролики и PNG находятся в `.qa/overdrive-finale/`. Клавиатурный режим проверен отдельно.
- Воспроизводимость аудио проверена с NumPy 2.3.5 и SciPy 1.17.0 командой `python games/chess/overdrive/scripts/generate-overdrive-audio.py`. Геометрия воспроизводится командой `node games/chess/overdrive/scripts/bake-finale-contacts.mjs`.

Ролики записаны с отключённым звуком. В этой среде нет доступного исполнителю слухового канала для оценки тембра. Для прослушивания на колонках или наушниках Mac подготовлены отдельные сигналы и игровые комбинации на порту 4198. Физический телефон в этом прогоне не использовался.

## Независимая приёмка
