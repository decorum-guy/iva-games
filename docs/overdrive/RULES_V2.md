# Форсаж: энергия, версия 2

Новые партии используют `overdrive-v2`: две банки по три деления, максимум 6. Импульс стоит 3, активация форсажа — 6. Взятие даёт энергию по фигуре: пешка +1, конь или слон +2, ладья +3, ферзь +4. Новый шах по-прежнему даёт +2. Действует предел вместимости, а энергию текущего хода нельзя потратить заранее.

Действующие сохранённые партии и гостевые комнаты `overdrive-v1` продолжают обрабатываться по исходным правилам, включая банки по пять и +1 за любое взятие. Новая партия и реванш используют v2. Браузерные сохранения и база комнат остаются на прежних местах. Сетевой протокол обновлён до `overdrive-online-v2`: старым открытым вкладкам для сетевой игры нужно обновить страницу. Историческое описание: [RULES_V1.md](RULES_V1.md).
