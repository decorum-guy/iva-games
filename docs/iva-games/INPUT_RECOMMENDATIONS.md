# Рекомендации управления на карточках игр

`packages/game-registry/games.json` — единственный источник рекомендации. Необязательное поле записи игры:

```json
"inputRecommendation": "mouse"
```

Поле означает совет для удобства, не требование устройства. Его отсутствие означает отсутствие наклейки. Валидатор разрешает только `"mouse"`; `true`, `false`, `null` и отдельные клиентские флаги не используются. Поле не меняет доступность игры, комнаты, запуск, поддержку касания или трекпада.

Ставить рекомендацию нужно после проверки реального управления: например, постоянный mouse-look, быстрый поворот с наведением или действия, которым заметно помогает отдельная мышь. Само наличие 3D, кликов, доски или версии для компьютера не является основанием. Принятые шахматы нормально работают с касанием и трекпадом; REMORSE, Форсаж и Колосс остаются без отметки. Район, Гавань и Пробный стол этим изменением тоже не отмечены.

## Подключение «Сначала постучи»

Владелец явно рекомендовал мышь для Knock First. При интеграции принятой игры добавить поле **в её существующую запись** `packages/game-registry/games.json`, рядом с `roomStatus`:

```json
{
  "gameId": "knock-first",
  "inputRecommendation": "mouse",
  "deviceAvailability": "desktop-only"
}
```

Это частичный пример изменения записи, не полная регистрация. Сохранить прочие поля, маршрут и runtime кандидата. Не добавлять вторую запись и не переносить feature-игру в `main` только ради наклейки. В этой ветке Knock First не регистрируется и не выпускается.

## Доступность на устройствах

Последующее прямое решение владельца закрывает мобильный запуск Knock First. Это **отдельное** необязательное поле `deviceAvailability: "desktop-only"`, не следствие рекомендации мыши. Без него игра доступна на всех устройствах. В `games.json` хранятся оба независимых решения; отдельные списки ID запрещены.

Общий экспорт `isGameAvailableOnDevice(gameId, navigator)` из `@iva-games/game-registry` используется карточкой и guard самой игры **до** создания live-controller, готовности или запуска. `isMobileDevice` — чистая проверка UA/UAData: Android, iPhone/iPad/iPod, мобильный UA либо iPadOS с MacIntel/Macintosh и несколькими touch points. Ширина окна, `pointer: coarse` и наличие touch сами по себе не определяют мобильное устройство: узкое окно, трекпад и Windows/Linux с touchscreen остаются компьютерами. Серверной авторизацией или защитой от подмены UA эта проверка не является.

У недоступной мобильной карточки вместо ссылки/кнопки запуска показан текст **«Играйте на компьютере»** / **“Play on a computer”**. Шахматы и остальной портал не получают мобильного запрета. Guard Knock First интегрирует ответственный исполнитель feature-игры; наличие поля или наклейки не доказывает его выполнение.

## Общий вид и текст

`apps/portal/src/GameCard.tsx` используется настоящими карточками `/chess`, `/games` и самостоятельной шахматной коллекции. Он читает поле реестра по `gameId`; API-каталог, игровые пакеты и аккаунты не хранят дубликат рекомендации. Коллекции на главной странице обозначают разделы, не игры, и наклейку не получают.

Единые видимые и доступные тексты: **«Удобнее с мышью»** / **“Better with a mouse”**. Текст находится вне декоративного `aria-hidden` арта, иконка скрыта от скринридера. Наклейка — обычный текст без собственного фокуса и обработчиков; она не перехватывает указатель. Светлая бумага, отдельный край, небольшой загиб, тень и постоянный наклон −3° отделяют её от статусного тега. Положение ограничено иллюстрацией и не закрывает заголовок или действие.

Оригинальная SVG-иконка хранится в `apps/portal/src/assets/mouse-recommendation.svg`, материал — в `game-card.css`. Заимствованные изображения, шрифтовые символы мыши и emoji не используются.
