## Выполнено

- `npm ci`, `npm run check:platform` (68 тестов), `npm run build:foundation`, `npm run check` (749 тестов в 54 файлах), `npm run build:all`, `npm run platform:smoke` — успешно. Smoke использовал отдельные временные данные и не отправлял сообщений; это HTTP, не браузер.
- Headless Chromium, два независимых cookie-контекста: регистрация и явное подтверждение двух аккаунтов по письму, поиск, отправка и принятие дружбы, создание комнаты, адресное приглашение, принятие и отдельный вход, готовность и игра вдвоём до результата. Обновление сохраняло результат. Восстановление пароля через файловое письмо, повторное открытие ссылки до подтверждения, сброс, отзыв старой сессии и новый вход прошли.
- Через UI создана и завершена партия на шесть мест: один человек и пять ботов; все три раунда показали результат. Для повторных действий и рестарта отдельно пройден HTTP smoke.
- На 390×844 и 1280×844 проверены страницы игр, друзей, комнат и приглашений на английском, горизонтального переполнения документа не обнаружено; на мобильном размере визуально осмотрена страница друзей. Проверено наличие outline у первого элемента при Tab. Это эмуляция, не физический телефон и не полная проверка доступности.
- Изолированная постоянная демонстрация: отдельные SQLite-файлы и локальная почта в `.runtime/acceptance-demo`. Два проверенных аккаунта и пароли хранятся только в локальном файле `credentials.txt` с правами 0600. Скрипт `scripts/iva-local-demo.sh` запускает и останавливает только свои процессы; старт, ответ сайта и API, остановка и повторный старт проверены. Процессы шахмат на 4173 и 4185 не останавливались.

## Ещё не подтверждено

Полный набор пользовательских случаев задания ещё не пройден: встречные и отклонённые заявки, отмена, блокировка и приватность профиля; посторонний пользователь и истечение/отзыв резерва; передача host, изменение состава и сброс готовности; смешанная партия; UI после разрыва сети и перезапуска; проверка большого объёма истории через UI; контролируемые экраны Telegram; полная RU/EN и доступность с увеличенным текстом. Автотесты и HTTP smoke не следует выдавать за эти браузерные проверки. Реальная почта, HTTPS, выделенный Telegram-бот, webhook, proxy route и согласованный получатель для живой доставки пока не подтверждены. Шахматный адаптер и публичный выпуск вне этой итерации.
