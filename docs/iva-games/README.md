# Iva Games — проект и платформа

Шахматный интерфейс: [единый путь запуска](CHESS_ENTRY_FLOW.md). Текущая очередь новых игр: [аудит пяти веток от 28 ноября](GAME_BRANCH_AUDIT_2026_11_28.md).

Актуально на 27 ноября 2026 года. **Портал, обе шахматные игры и Район v0.3 опубликованы по переданному владельцем отчёту.** Район технически работает, но его карта и игровой цикл ещё не приняты владельцем. Текущий статус, источники и следующий этап — [BUILD_STATUS.md](BUILD_STATUS.md). Общая роль веб-агента и работа с локальными исполнителями — [AGENT_ROLES.md](AGENT_ROLES.md).

## Основание и принятые решения

Прямые указания владельца: общий проект игр для себя, девушки и друзей; единый репозиторий Iva Games; шахматы в `games/chess/<variant>`; обязательные аккаунты, друзья, комнаты и приглашения; добровольная Telegram-привязка со стартом по ссылке; исходящий Telegram-трафик через существующий `kz-bot`. Рабочий GitHub-адрес **decorum-guy/iva-games** подтверждён по постоянному repository ID 1469444922.

Выбраны «Гавань» и «Район». После выпуска v0.3 владелец уточнил: «Район» должен быть гораздо ближе к Colonist по самому игровому процессу — освоение территории, ресурсы, торговля, дороги, порты и тактические возможности — с дополнительными собственными механиками. Нужны большая читаемая 2.5D-карта, три разные географии и лёгкое интерактивное обучение. **Боты обязательны**, включая одного человека с ботами и смешанные комнаты. [Исследование и границы наблюдений](../../games/district/COLONIST_RESEARCH_2026_11_27.md) и [задание на новую версию](../../prompts/REBUILD_DISTRICT_COLONIST_CORE.md) заменяют прежнюю трактовку этой обратной связи как исключительно художественной переделки. Заявление, что игра уже лучше референса, не является проверенным результатом.

Инженерное решение: сохранить TypeScript/React/Node, отделить platform-service (аккаунты, социальная модель, lobby и доставка), session-kit (контракты игровых сессий) и engine-sdk (поиск для подходящих двухсторонних игр). Правила и приватное состояние принадлежат конкретной игре. Идентификатор участника отличается от учётной записи: бот занимает место, но не получает email, cookie или друзей.

## Что находится в репозитории

| Область | Содержание и граница |
|---|---|
| [apps/platform](../../apps/platform/README.md) | Настоящие аккаунты, восстановление, друзья/блокировки, приватные комнаты, сайт-приглашения, готовность и устойчивый запуск runtime |
| [apps/portal](../../apps/portal/README.md) | Подключённый к API интерфейс RU/EN; наличие сборки отдельно от визуальной приёмки |
| [packages/session-kit](../../packages/session-kit/src/types.ts) | Контракты runtime и техническая партия на 2–6 мест с приватными решениями, ботами и сохранением |
| [packages/telegram-transport](../../packages/telegram-transport/src/index.ts) | Серверный транспорт с обязательным прокси и без прямого fallback |
| [«Район»](../../games/district/STATUS.md) | Реализованная v0.3: три островные карты, торговля, аукционы, недвижимость, цели и боты. Новая территориальная версия и интерактивное обучение предстоят |
| [«Гавань»](../../games/harbor/CONCEPT.md) | Концепция торговли, рейсов, скрытой информации и контрактов; полный набор правил впереди |
| Шахматная коллекция | Опубликованный перенос и исправления Mac-приёмки `c18e57c` интегрированы; принятые исходники игр/SDK/шахматного сервера сохранены. Адаптер к общим аккаунтам и комнатам ещё предстоит |

Технический «Пробный стол» проверяет общий фундамент. Он не заменяет полноценные правила, ботов или художественную приёмку «Района».

## История интеграции шахматной ветки

Следующий раздел описывает прежнюю интеграцию, а не нынешние открытые PR или состояние production.

Платформенная ветка начата от документационного коммита `635520cb408d17d1361d30cf154fbc0a95f40c87`. Первый опубликованный кодовый milestone — `bdccf51`; затем согласована документация шахматного переноса `2949209`. После сообщения владельца о завершении Mac-приёмки включён её опубликованный результат `c18e57c`. Сравнение с этим принятым снимком не показывает изменений в `games/chess`, `packages/engine-sdk` и `apps/server`. Текущий PR №5 основан на `acceptance/overdrive-monorepo` / PR №6, который следует за PR №3.

Новый код находится в отдельных `apps/portal`, `apps/platform` и `packages/*`. Вложенные шахматные пакеты взяты из опубликованного переноса, без копирования старого `src/` поверх них и без смены идентификаторов сохранений. Исторические отчёты Remorse/Overdrive относятся только к указанным в них ревизиям. Платформенная ветка не означает слияния в main или изменения активного сервера владельца.
