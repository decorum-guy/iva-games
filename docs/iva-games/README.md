# Iva Games — проект и платформа

Дата: 25 ноября 2026 года. **Есть исходники общего портала и сервера; новые экономические игры остаются на стадии проектирования.** Подробный фактический отчёт — [BUILD_STATUS.md](BUILD_STATUS.md).

## Основание и принятые решения

Прямые указания владельца: общий проект игр для себя, девушки и друзей; единый репозиторий Iva Games; шахматы в `games/chess/<variant>`; обязательные аккаунты, друзья, комнаты и приглашения; добровольная Telegram-привязка со стартом по ссылке; исходящий Telegram-трафик через существующий `kz-bot`. Рабочий GitHub-адрес **decorum-guy/iva-games** подтверждён по постоянному repository ID 1469444922.

Выбраны «Гавань» и «Район». Последнее уточнение владельца задаёт «Району» социальную экономику в духе Colonist, Monopoly One и Jackbox: сделки, поводы для переговоров, забавные последствия событий и возможность регулярно менять игру по обратной связи друзей. **Боты обязательны с первого игрового выпуска**, включая одного человека с ботами и смешанные комнаты. Это требование; утверждение, что будущая игра уже лучше референсов, не является проверенным результатом.

Инженерное решение: сохранить TypeScript/React/Node, отделить platform-service (аккаунты, социальная модель, lobby и доставка), session-kit (контракты игровых сессий) и engine-sdk (поиск для подходящих двухсторонних игр). Правила и приватное состояние принадлежат конкретной игре. Идентификатор участника отличается от учётной записи: бот занимает место, но не получает email, cookie или друзей.

## Совместная работа с шахматной веткой

Платформенная ветка начата от документационного коммита `635520cb408d17d1361d30cf154fbc0a95f40c87`. Первый опубликованный кодовый milestone — `bdccf51`; затем согласована документация шахматного переноса `2949209`. После сообщения владельца о завершении Mac-приёмки включён её опубликованный результат `c18e57c`. Сравнение с этим принятым снимком не показывает изменений в `games/chess`, `packages/engine-sdk` и `apps/server`. Текущий PR №5 основан на `acceptance/overdrive-monorepo` / PR №6, который следует за PR №3.

Новый код находится в отдельных `apps/portal`, `apps/platform` и `packages/*`. Вложенные шахматные пакеты взяты из опубликованного переноса, без копирования старого `src/` поверх них и без смены идентификаторов сохранений. Исторические отчёты Remorse/Overdrive относятся только к указанным в них ревизиям. Платформенная ветка не означает слияния в main или изменения активного сервера владельца.
