# Iva Games — проект и платформа

Обновлено 26 ноября 2026 года. **Начинайте с [PROJECT_STATUS.md](PROJECT_STATUS.md):** портал и Форсаж реализованы, публичная приёмка ещё должна быть подтверждена; «Район» имеет полные правила прототипа, но пока не игровое приложение. [BUILD_STATUS.md](BUILD_STATUS.md) сохраняет подробные журналы этапов.

## Основание и принятые решения

Прямые указания владельца: общий проект игр для себя, девушки и друзей; единый репозиторий Iva Games; шахматы в `games/chess/<variant>`; обязательные аккаунты, друзья, комнаты и приглашения. Текущий production использует [Telegram-аккаунты](TELEGRAM_ACCOUNTS.md) без SMTP. Первичная настройка бота с Mac использует `kz-bot`; runtime отвечает через webhook. Прежняя добровольная привязка и исходящие приглашения — отдельная интеграция. GitHub-репозиторий — **decorum-guy/iva-games**, ID 1469444922.

Выбраны «Гавань» и «Район». Последнее уточнение владельца задаёт «Району» социальную экономику в духе Colonist, Monopoly One и Jackbox: сделки, поводы для переговоров, забавные последствия событий и возможность регулярно менять игру по обратной связи друзей. **Боты обязательны с первого игрового выпуска**, включая одного человека с ботами и смешанные комнаты. Это требование; утверждение, что будущая игра уже лучше референсов, не является проверенным результатом.

Инженерное решение: сохранить TypeScript/React/Node, отделить platform-service (аккаунты, социальная модель, lobby и доставка), session-kit (контракты игровых сессий) и engine-sdk (поиск для подходящих двухсторонних игр). Правила и приватное состояние принадлежат конкретной игре. Идентификатор участника отличается от учётной записи: бот занимает место, но не получает email, cookie или друзей.

## История совместной работы с шахматной веткой

Этот раздел описывает прежнюю последовательность интеграции. Принятый результат уже находится в main; перечисленные старые PR не являются текущей точкой продолжения. Используйте общую сводку выше.

Платформенная ветка начата от документационного коммита `635520cb408d17d1361d30cf154fbc0a95f40c87`. Первый опубликованный кодовый milestone — `bdccf51`; затем согласована документация шахматного переноса `2949209`. После сообщения владельца о завершении Mac-приёмки включён её опубликованный результат `c18e57c`. На том этапе сравнение с принятым снимком не показывало изменений в `games/chess`, `packages/engine-sdk` и `apps/server`. Тогда PR №5 был основан на `acceptance/overdrive-monorepo` / PR №6, следовавшем за PR №3.

Новый код находится в отдельных `apps/portal`, `apps/platform` и `packages/*`. Вложенные шахматные пакеты взяты из опубликованного переноса, без копирования старого `src/` поверх них и без смены идентификаторов сохранений. Исторические отчёты Remorse/Overdrive относятся только к указанным в них ревизиям. Платформенная ветка не означает слияния в main или изменения активного сервера владельца.
