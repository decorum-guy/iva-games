# Iva Games — проектный пакет

Дата: 25 ноября 2026 года. Статус: **согласованное направление и проектные спецификации; новый код платформы и нешахматных игр ещё не реализован**.

## Основание

Владелец расширил МОИ ИГРЫ от семейства Chess 2 до общего портала собственных браузерных игр для себя, девушки и друзей. Этот пакет записывает его прямые указания и предложенные инженерные/игровые решения отдельно от подтверждённой реализации.

### Прямые указания владельца

- Один общий репозиторий; рабочее имя проекта **Iva Games**, целевой вариант имени репозитория — **iva-games**, вместо ранее обсуждавшегося chess-2.
- Шахматные игры находятся в **games/chess/remorse**, **games/chess/overdrive** и аналогичных каталогах будущих вариантов.
- В шахматной коллекции ожидаются ещё 2–3 варианта. Ранее выбранные направления и исключения не пересматриваются этим пакетом.
- Для следующей нешахматной работы выбраны **«Гавань»** и **«Район»** (в разговоре также назван «Город»). Обе идеи следует записать; одну — подробно проработать концептуально.
- До продуктовой реализации этих игр нужен общий фундамент: вход на сайт, друзья, комнаты и приглашения.
- Приглашения доступны на сайте и через добровольно подключённого Telegram-бота. Связка начинается с кнопки на сайте и ссылки с кодом, которую пользователь открывает в Telegram и запускает через Start.

### Предложения этого пакета

- Первым подробно проработать «Район»: он проектируется для 2–4 игроков с полноценной партией вдвоём. «Гавань» ориентировать на 3–6 человек.
- Разделить platform-service (аккаунты, друзья, приглашения и доставка уведомлений), session-kit (общая механика игровых сессий) и существующий engine-sdk (поиск для подходящих двухсторонних игр).
- Подтверждать обнаруженный Telegram-аккаунт в исходной веб-сессии перед окончательной привязкой.
- Развивать существующий TypeScript/React/Node стек, выделяя независимо запускаемые приложения по мере необходимости.

Это проектные решения, которые можно уточнять по результатам разработки и пробных партий. Числа экономики, лимиты и длительности не являются проверенным балансом или измеренной нагрузкой.
