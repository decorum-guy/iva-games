# Понятное начало шахматной игры

Решение владельца от 28 ноября 2026: визуальный стиль у каждой игры свой, путь игрока общий. Этот контракт обязателен для REMORSE, OVERDRIVE, COLOSSUS и будущих шахматных игр.

## Первый экран

- Без незаконченной партии главный путь — **«Новая партия» → «Начать партию»**. При сразу открытых параметрах остаётся только «Начать партию». Принятые настройки по умолчанию позволяют начать за одно-два нажатия без обязательного заполнения имени.
- При незаконченной партии главное действие — **«Продолжить»**. Допустимо сразу вернуть игрока к его доске. Завершённая партия не считается незаконченной; её результат и история остаются доступны.
- Второстепенные входы — **«Обучение»**, **«С другом»**, **«Настройки»**. «С другом» предлагает один экран выбора: на одном устройстве или по сети. Приглашение ведёт сразу в свою комнату, без обхода через новое меню.
- «Новая партия» и «Продолжить» не должны конкурировать двумя одинаково яркими кнопками. Открытие меню, настроек или урока не начинает новую партию и не заменяет сохранённую.

## Параметры партии

Сначала показываем выбранный режим и сложность. Редкие параметры (цвет, имена, колода, карты босса, специальные режимы) раскрываются по явному запросу. Значения по умолчанию соответствуют принятым правилам; сворачивание параметра не меняет его значение. Выбор рейтинговой партии остаётся видимым: он определяет последствия результата. Активный рейтинг или нестандартный режим должен быть понятен до старта.

Все режимы остаются доступны. Поход и практика Колосса находятся в «Других режимах и колоде»; подробности правил — в справке, рекорды и старые партии — в соответствующем разделе. Не заставляем новичка разбираться с коллекцией карт до первого боя. Для игры с одним слотом сохранения замена незаконченной партии требует явного подтверждения. Для нескольких слотов достаточно сохранить прежнюю партию; особое правило незаконченной рейтинговой REMORSE сохраняется.

## Во время игры

Меню открывается в одном очевидном месте. Из него доступны продолжение, новая партия, обучение и игра с другом. Названия действий совпадают в RU/EN: New game, Continue, Tutorial, With a friend, Settings. Звук, типографика, модели, материалы, фон и компоновка сохраняют характер конкретной игры; общий путь не требует общей темы оформления.

Одна кнопка выполняет одно понятное действие. Не показываем одновременно все режимы, сетевые формы, редактор, колоду и длинные объяснения. Один вложенный уровень для редких параметров достаточен; не создаём цепочку из трёх меню. Справка не является обязательным шагом запуска.

## Проверка перед выпуском

Исполнитель проходит свежий вход, старт с настройками по умолчанию, возврат к незаконченной партии после reload, новую партию с сохранением прежней, обучение с возвратом и оба пути игры с другом. Проверяет RU/EN, клавиатуру, 390 px и низкий экран, видимость главного действия, отсутствие горизонтальной прокрутки и доступные имена иконок. Изменённое меню проверяется на итоговой сборке; старый отчёт не принимает новое меню.

В PR описываются последовательность нажатий и сохранность партии. Новый пункт первого экрана добавляется только если он нужен для обычного старта; иначе используется существующее раскрытие. Ревьюер сверяет этот контракт, а не число реализованных настроек. Правила, баланс, сетевые версии и ключи сохранений ради единого меню не меняются.
