**Последние обязательные решения по новостям:** четыре пресета частоты/жёсткости; 0, 1 или 2 предупреждения, включая отсутствие предупреждения; прогноз может не сбыться. До фактического эффекта видны только новость и контур сектора/всей карты, без перечня будущих пострадавших, зданий и сумм. После эффекта перечисляются реальные последствия. Эпидемия может начаться в секторе и затем вероятностно распространиться на карту; расширение области риска ещё не является применением общего ущерба. Сохраняй скрытые исходы на сервере и версии старых матчей. Численные параметры требуют оценки, а не объявления универсального баланса.

**Предрелизная проверка Района v0.4:** на `c37cc1ccfe08c91e5a19ad3c11e6871e597a6904` успешен CI платформы и обоих образов, повторно проверены 17 стадий в двух браузерах, 26 SQLite-сценариев сбоя и повтора, все пресеты на трёх картах и восстановленная копия production. Проверено открытие сохранённой v0.4-партии и создание комнаты v0.3 с выключенным флагом. Следующая проверка — игровая приёмка владельца, затем отдельно согласованный выпуск с проверкой актуального `main` и итогового SHA. [PR №10 Colossus](https://github.com/decorum-guy/iva-games/pull/10) и [PR №14 Gemini/AGY](https://github.com/decorum-guy/iva-games/pull/14) остаются открытыми по проверенным метаданным; их не нужно автоматически объединять вместе с текущим заданием. Новый чат выполняет согласованную работу сам и через реально доступных исполнителей, поддерживает короткие тексты UI и публикует законченные этапы. Сохраняет чужие ветки/локальные процессы, проверяет доступность инструментов, не обещает SSH или постоянного наблюдения из одного текста роли. Текущее разрешение на маленькую правку main и документы не является автоматическим разрешением публиковать новый игровой профиль. После каждого существенного этапа обновляй этот верхний раздел с точными источниками и дальнейшим действием.

## Вход через Telegram — 26 ноября 2026

Production настроен на аккаунты через личный чат Telegram, без SMTP. Выделенный бот подключён: на VPS приватный API сессии подтвердил `telegram: true`, запрос к webhook без секрета получил 401. Формат ответов webhook с тремя штатными стилями кнопок проверен тестами. Фактическую доставку, профиль и заявки в Telegram нужно будет проверить после публичного HTTPS.
