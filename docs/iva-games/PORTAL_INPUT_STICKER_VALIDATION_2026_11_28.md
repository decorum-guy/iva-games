Всего **36 состояний страниц**. Локальный API-каталог использовал снимок публичного ответа, а сессию — контролируемого гостя. Fixture добавлял только в локальную Vite-трансформацию JSON три синтетические регистрации: desktop-only пример Knock First, пример только с советом мыши и пример шахматной карточки для проверки второго каталога. Это не зарегистрированные публичные игры и не приёмка самой Knock First. Сверху страниц показано `ISOLATED REVIEW FIXTURE`, названия тестовых карточек тоже содержат `REVIEW FIXTURE`.

Исполнитель **сам открыл и осмотрел** реальные кадры публичных карточек и помеченных примеров в RU/EN на обоих размерах. Наклейка читаема, имеет светлый материал, отдельный край/загиб, тень и лёгкий наклон. Она находится внутри иллюстрации, не закрывает название или действие. Светлая иконка мыши не заменена emoji. На телефонном примере Knock First показаны «Для компьютера» и «Играйте на компьютере» / “Computer only” и “Play on a computer”; у примера только с рекомендацией действие остаётся доступно.

В том же браузерном проходе проверены:

- наклейка только у явно помеченных регистраций; у всех существующих карточек её нет;
- точные RU/EN строки, доступный текст вне `aria-hidden`, загрузка оригинальной SVG;
- границы наклейки внутри арта, отсутствие пересечения с заголовком/действием и горизонтального переполнения;
- настоящий hover, клавиатурный фокус и видимая рамка фокуса на действиях помеченных карточек; наклейка не перехватывает указатель;
- у mobile desktop-only примера нет кнопки/ссылки запуска; видимый текст объясняет дальнейшее действие; рекомендация мыши сама по себе запуск не блокирует.

Все **12 локальных PNG без новых меток побайтно совпали** с соответствующими публичными PNG: три поверхности × два размера × RU/EN. Это отдельная проверка сохранения вида нынешних карточек, не только измерение геометрии.

Дополнительные пробы идентичности устройства на Chromium: iPadOS с desktop Safari UA, `MacIntel` и пятью touch points получил мобильную подсказку; Windows desktop UA с десятью touch points и окном **320 px** сохранил действие запуска. Оба кадра осмотрены. Настоящие Safari/iPad/телефон этими эмуляциями не объявляются проверенными.

## Передача Knock First

С Terra согласован один контракт. В существующей feature-записи `gameId: "knock-first"` нужны **два независимых поля**: `inputRecommendation: "mouse"`, `deviceAvailability: "desktop-only"`. Карточка и guard до live-controller используют `isGameAvailableOnDevice('knock-first', navigator)` из общего пакета. Сам guard находится в отдельной работе Terra; её checkpoint `976c4d5ff92dbfb3f82fa19bb4d591c4445ca9c9` и его игровые проверки этим исполнителем не пересобирались и не принимаются через снимки каталога.

Координатору остаются независимый просмотр diff/кадров, интеграция со свежим `main`, штатный итоговый CI и разрешённый выпуск. Исходная feature-игра не должна попадать в `main` ради демонстрации наклейки.
