## Настоящий GitHub CI

Для `1e54f60` непосредственно получены состояния завершённых workflow и каждого существенного шага:

1. [Iva Games platform, запуск №15](https://github.com/decorum-guy/iva-games/actions/runs/45715073884), `completed / success`: checkout, Node, npm ci, общий check, build:all и platform:smoke.
2. [Iva Games release images, запуск №1](https://github.com/decorum-guy/iva-games/actions/runs/45715073979), `completed / success`: отдельные задания `chess image` и `platform image`, оба со сборкой и запуском runtime.

В Docker CI реально выполнены:

- Сборка обоих Dockerfile, включая production-зависимости и нативный SQLite binding.
- Запуск от непривилегированного пользователя с `NODE_ENV=production`, read-only корнем, `/tmp`, отдельным volume и `--network none`.
- Штатный healthcheck, содержимое JSON health, загрузка HTML и настоящих JS/CSS.
- Создание через HTTP гостевых шахматных/анонимных платформенных сессий, проверка защищённых cookie и записей SQLite.
- Проверки таблиц, WAL, `quick_check` и внешних ключей обеих БД каждого приложения.
- Чистая остановка, создание нового контейнера на том же volume и проверка сохранённых записей.

Платформа использовала недоставляющие CI-значения `mail.invalid` и `ci@example.invalid`; SMTP-сервера не было, отправка почты не вызывалась. Telegram выключен. Это проверка production startup и сохранения данных, **не проверка почты, Telegram, публичного HTTPS или Compose/Caddy**. Образы и тестовые данные не публиковались в registry/artifacts; временные контейнеры и volumes удалены.

## Баланс и решение по Форсажу

Полная методика, отдельные результаты трёх серий, найденная избежимая дебютная ловушка, энергетические возвраты, пределы глубины поиска и хеши записаны в [BALANCE_ENERGY_V2.md](../overdrive/BALANCE_ENERGY_V2.md).

Рекомендация аудита — сохранить согласованные 3/6 и награды за фигуры. Самоигра не выявила явного доминирования цвета или ротационного превращения. Она подтвердила более раннюю активацию и более частые приёмы, но не гарантированное сокращение длины партий. Это не человеческий Elo и не строгая гарантия равных шансов.

## Публичный выпуск ещё не выполнен

Готов [конкретный пакет выпуска](RELEASE_IVA_GAMES_PRO.md): `iva-games.pro` для портала, `chess.iva-games.pro` для REMORSE и `/overdrive/` для Форсажа; отдельные образы и данные, выборочное обновление, backup и совместимый откат. Покупка домена известна из сообщения владельца. Настроенные DNS/HTTPS этим не подтверждены.

Остаются фактический целевой сервер и его текущий reverse proxy, DNS/HTTPS, настоящая SMTP-конфигурация, испытание backup/restore на выбранном сервере и публичная проверка двух независимых клиентов. Для Telegram дополнительно нужны выделенный бот, его секреты, webhook и проверенный из нового runtime маршрут через `kz-bot`, затем разрешённый тестовый получатель. Реальных писем и Telegram-сообщений в этом проходе не отправляли.

Новейший отчёт PR №7 уже подтверждает Mac SSH к `kz-bot` и существующий SOCKS5/TLS-маршрут с `ha-vps`. Старое зависание SSH не является текущим подтверждённым блокером. Это не равнозначно подключению нашего бота.

Общие аккаунты и комнаты пока не интегрированы с шахматными гостевыми комнатами. Район и Гавань остаются концепциями, «Пробный стол» — отдельной рабочей игрой платформы. Автоматическое развёртывание после push ещё не включено: нынешние workflow проверяют код и образы.
