## Очерёдность

1. Закончить аудит правил REMORSE, упростить справку и обучение, реализовать и проверить настоящую сетевую игру.
2. Подготовить сервер и опубликовать REMORSE на `https://remorse.chess-2.online`.
3. Когда появится ещё одна игра, попросить Claude разработать дизайн общего каталога для `chess-2.online`.

Ограничение предыдущего этапа: каталог не должен был подменять доработку REMORSE. Новый запрос разрешает архитектурную проработку общего портала; его реализация идёт по отдельному [плану Iva Games](iva-games/DELIVERY_PLAN.md). Существующие выбранные оформление и звуки REMORSE сохраняются, прежние планы художественного дизайна каталога не объявляются выполненными.

## Требования к публикации REMORSE

- Frontend, API и WebSocket одной игры работают с одного origin: `https://remorse.chess-2.online` и `wss://remorse.chess-2.online/ws`.
- Адреса клиента строятся от текущего origin; локальная разработка и проверки остаются возможны без публичного домена.
- Гостевые сетевые сессии ограничены хостом REMORSE. Не устанавливать cookie с `Domain=chess-2.online`: будущие игры не должны автоматически получать её игровые права.
- При настройке reverse proxy и Origin-проверок использовать адрес REMORSE. Корневой домен и другие поддомены оставить для согласованного будущего каталога и игр.
- DNS, доступ к серверу, сертификат и работа из разных сетей проверяются отдельно при публикации. Наличие купленного домена не означает, что эти шаги уже выполнены.

## Идеи следующих игр

В [CHESS_2_GAME_IDEAS.md](CHESS_2_GAME_IDEAS.md) сохранена история обсуждения. Более поздние выбранные шахматные направления — Форсаж, Джокер, Хор, Химера и Связь; Эстафета исключена. Код Форсажа находится в `games/chess/overdrive`, REMORSE — в `games/chess/remorse`, общий поиск — в `packages/engine-sdk`. Кандидат поставляется через [feat/overdrive-sdk](https://github.com/decorum-guy/remorse-chess/tree/feat/overdrive-sdk) / draft PR №3; это не подтверждает слияние в main, живую приёмку или выпуск. Текущее состояние Форсажа — в [overdrive/STATUS.md](overdrive/STATUS.md). Отдельный публичный адрес Форсажа ещё не подтверждён и не настроен. Новые нешахматные концепции — [«Район»](../games/district/CONCEPT.md) и [«Гавань»](../games/harbor/CONCEPT.md).
