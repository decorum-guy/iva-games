# Локальный выбор звуков REMORSE

[Открыть сравнение](http://127.0.0.1:4174/auditions.html). Выберите одну из семи групп, переключайте «Текущий», R1/R2 или P1/P2 и запускайте сцену кнопкой «Проиграть». «Выбрать звук» добавляет вариант в список. «Копировать выбор» готовит сообщение для установки. Громкость и выбор относятся к этой странице.

Для ферзя «Только звук раскола» воспроизводит ту же постановку с одним слоем. `CURRENT-STONE-SOLO` означает штатный звук раскола. `P1-STONE-SOLO` означает подготовленный изолированный камень P1. При выборе полной сцены P1 или P2 камень уже входит в этот микс. Текущий звук и P1/P2 используют отдельные звуки хода или броска, если они есть в примере. В режиме solo слышен один каменный слой. `R2-BLOODLUST-SHORT` означает игровой отрезок на 1,54 с. Шестисекундный исходник воспроизводится отдельной кнопкой в «О записи».

## Запуск на Mac

```sh
npm run auditions:build
npm run auditions:preview
```

Страница собирается в `.qa/sfx-audition/production/` и доступна по loopback на 4174. Основная игра использует отдельный origin на 4173. `npm run auditions:test` запускает отдельные тесты Chromium и WebKit. Сборка обычной игры по-прежнему использует `index.html`.

## Монтаж для сравнения

Доска и кубик используют штатный WebGL-рендер. Позиции проходят `applyResolvedCommand`, поэтому грани 2, 1 и 6 дают вину, опустошение и ярость, а третье взятие уже разъярённой фигурой даёт жажду крови без броска. Для всех звуков одной сцены положение, ракурс, качество, результаты и ключ разлома одинаковы. Короткий режим берёт игровые сроки из `actionPlan` и `promotionTiming`.

Штатные записи воспроизводятся из `board.wav` с игровыми окнами, скоростью, gain и компрессором. Кандидаты декодируются заранее в `OfflineAudioContext`. Аудиовыход открывается по нажатию. Изображение и звук получают общую отметку `performance.now()` с запасом 80 мс на постановку пакета. При смене группы, варианта, режима движения, повторе, Stop и скрытии страницы очередь отменяется с техническим отпусканием 18 мс. Из хранилищ используется только отдельный `remorse-audition-choices-v1` для явно отмеченных вариантов.

Монтаж задан в `src/auditions/audio.ts`. Границы ниже в секундах относительно декодированного MP3. Gain дополнительный, до общего компрессора и регулятора громкости. У кандидатов входной fade 0,014 с. Согласование уровня опирается на кратковременный RMS и запас по пикам. Воспринимаемая громкость и тембр остаются предметом прослушивания владельца.

| Сцена | Вариант | Отрезок | Gain | Затухание |
|---|---|---|---|---|
| Вина | R1 | 0–1,40 | −8 dB | 0,23 |
| Опустошение | R1 | 0,29–1,67 | −8 dB | 0,24 |
| Ярость | R1 | 0,40–1,66 | −12 dB | 0,24 |
| Жажда крови | R1 | 0,57–1,98 | −8 dB | 0,25 |
| Вина | R2 | 0,22–1,433 | −8 dB | 0,25 |
| Опустошение | R2 | 0,16–1,20 | −2 dB | 0,20 |
| Ярость | R2 | 0,36–1,20 | −2 dB | 0,20 |
| Жажда крови | R2-BLOODLUST-SHORT | 0–1,54 | −7 dB | 0,24 |
| Исходный chant отдельной кнопкой | R2 | 0–6 | −7 dB | 0,12 |

У слона/коня отметка основного слоя 0,160 у P1 или 0,120 у P2 приходит на штатный cue через 0,150 с от формирования или через 0,055 с в коротком режиме. Gain P1 −8 dB, P2 −5 dB. Отрезок заканчивается при завершении формирования.

У ладьи и ферзя маркер контакта 0,420 с. Начало вычисляется как `formationAt + impact − 0.420`. В коротком режиме клип стартует вместе с формированием с offset 0,285 с у ладьи и 0,240 с у ферзя. Gain ладьи −6 dB P1 и −8 dB P2, ферзя −6 dB P1 и −8 dB P2. Для полного ферзя хвост затухает за 0,32 с, у ладьи и появления за 0,22 с. В коротком режиме fade 0,14 с. Звуковые отрезки завершаются к штатному окончанию сцены.

Камень в P1 и его solo содержит три исходных надлома через 70, 200 и 440 мс после контакта. У P2 в полном миксе они через 60, 250 и 550 мс. Они следуют раскрытию и распространению существующего объёмного разлома. Demo-позиция оставляет чёрную ладью на d8 рядом с ферзём. P1 solo использует gain полного P1 и его же окно. Штатный solo воспроизводит только `promotionQueenFracture`. P2 доступен целым миксом.
