## Независимая визуальная приёмка

Отдельный агент **`gpt-6.1-terra` / `high`** управлял Chromium с открытым окном на Mac. Он прошёл оба маршрута обучения в 3D, играл за обе стороны в локальном режиме, проверил ход бота и просмотрел кадры и записи движения. На первой итерации агент воспроизвёл подгонку масштаба посреди переворота, перекрытие ладьи счётчиком и обрезку перезапуска на 568×320. После исправлений он повторил эти сценарии, сыграл после переворота на ноутбучном и сенсорном мобильном размере и прошёл английский маршрут в низком качестве с уменьшенным движением. В финальной сборке `index-DxL2uVoO.js` отдельно повторены непрерывный переворот и первый учебный бросок с правильным раскрытием грани.

## Звук

Сравнили волновые формы 12 записей и вариантов из открытых библиотек. Банк `board.wav` (58 812 байт) собран из записей деревянного и пластикового кубика, шахматной фигуры на алебастре и керамического контакта. Бросок использует пять ударов с убывающей силой по таймингу 3D-кубика. Акцент реакции звучит после последнего контакта. Короткое затухание прекращает запланированные звуки при отмене, уходе с экрана или выключении звука. [Источники CC0 и лицензии](../THIRD_PARTY_NOTICES.md) · [Точные файлы и интервалы](../public/assets/audio/manifest.json)

В Chromium и WebKit проверены нативный Web Audio после жеста, первый ход бота, окончание сдачей, звук взятия ботом, совпадение пяти контактов с анимацией и тишина после отмены незавершённого броска. Состояние кнопки звука и громкость переживают перезагрузку. Нативный выход игры отдельно записан в Google Chrome 158.0.8127.37. В 2,16 секунды попали взятие и пять различимых ударов кубика, пик −5,87 dBFS, в этой записи клиппинга не было. Субъективное прослушивание через динамики или наушники не проводилось.

## Воспроизведение проверок

```bash
npm run check
npm run build -- --outDir .qa/playability-dist
npm run preview -- --host 127.0.0.1 --port 4175 --strictPort --outDir .qa/playability-dist
# In a separate terminal
REMORSE_TEST_PORT=4175 npm run test:e2e -- --output=.qa/playability-final
```

Node 26.3.0, npm 11.16.0, Playwright Chromium 159.0.8154.6 и WebKit 27.2. TypeScript, ESLint, production build и **189 модульных тестов в 11 файлах** прошли. В полном браузерном прогоне прошли **62 теста**, по 31 на движок. В них вошли локальные и тренировочные партии, девять уроков с обоими исходами в каждом языке, рейтинговые победа, ничья и поражение, единственное начисление при двух вкладках, сохранения и импорт, навигация и отмена посреди анимации, 2D при потере WebGL.

На `127.0.0.1:4173` и `192.168.31.44:4173` сверены HTML и SHA-256 звукового банка с проверенной сборкой. В Google Chrome через Wi‑Fi адрес сыграна 3D-партия вдвоём до мата с клавиатуры. В десяти отдельных тренировочных партиях в 2D каждый уровень сделал первый ход за белых и сохранил его в IndexedDB. В этом прогоне от запуска партии до сохранённого хода прошло от 117 до 1824 мс. Chrome использовал ANGLE Metal на Apple M5. Ошибок загрузки ресурсов и исключений страницы не было.

Мобильное касание, размеры, смена ориентации и WebKit проверены в эмуляции. Попытка запустить страницу на сопряжённом iPhone через CoreDevice закончилась ошибкой 1011. Физический телефон и Safari на нём остались без проверки. Vite сообщает о крупном общем 3D-модуле, около 543 кБ до gzip. Общий FPS на разных устройствах не измерялся. Скриншоты, видео, аудиосигнал и трассы хранятся локально в `.qa/`.
