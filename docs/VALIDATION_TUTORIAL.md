## Что увидел независимый приёмщик

Отдельный агент **`gpt-6.1-terra` / `high`** прошёл девять русских уроков в установленном Chrome 158.0.8127.37 с открытым окном на Mac при 1280×800. Первый проход шёл от чистого профиля по тексту, подсветке и кнопкам игры. До завершения маршрута приёмщик не получал координат или будущих результатов и не читал исходники уроков. После финала он сохранил текущую позицию и сыграл в тренировке против Remorse Engine 4/10. Бот сделал ответный ход.

Первое взятие связывает четвёрку с результатом «Без изменений» и даёт обязательную таблицу всех граней. В последующих уроках приёмщик смог объяснить запрет взятия при вине, трёхцикловый отсчёт опустошения, милосердие, лечение и память реакции. Он увидел последовательность стыда и смену армии, немедленное исцеление королём, исключение коня, переход к жажде крови и последствия превращения. В последнем задании формулировка ссылалась на подсвеченные ходы до выбора фигуры. Кнопка в конце урока о слоне называлась просто «Продолжить», хотя открывала новый урок. В обновлённой сборке обе инструкции называют конкретное следующее действие.

На исправленном кандидате `index-C619X04d.js` Terra прошла все девять английских уроков при 360×800 касаниями. Она восстановила удержанное пояснение с четвёркой после перезагрузки, проверила уточнённые инструкции и вторую развязку. После отмены настройки вернулся финал, после подтверждения появилась обычная начальная расстановка против ИИ. В горизонтали 568×320 агент увидел целиком таблицу граней, подсказку счётчика, объяснение жажды крови и обе кнопки финала.

На финальном `index-BD6KUXg1.js` Terra повторила бросок вины. На кадре остановки одновременно видны кубик с «2 · Вина» у края, подсветка ладьи и объяснение. Следующий кадр показывает приближенную ладью с золотыми прожилками уже после исчезновения карточки кубика.

## Что исправлено и перепроверено на Mac

| Сценарий | Наблюдение и исправление |
|---|---|
| Раскрытие эффекта | На первом просмотре карточка остановившегося кубика закрывала ладью в момент начала приближения. В финальной сборке на 1200×710, DPR 2, остановившийся объёмный кубик и число видны у края, а состояние ладьи появляется в центре одновременно с пояснением. Камера показала золотые прожилки на корпусе и удержала кадр. За 4,18 секунды ожидания чёрные не сходили. После подтверждения вернулся общий план, чёрные ответили и появилась следующая задача. |
| Плоская доска | В первом прогоне Chromium 2D ждала возврата камеры, которой в этом режиме нет. Ожидание теперь относится к 3D с включённым движением. Смена на 2D во время возврата освобождает следующий скрипт один раз. |
| Мобильная компоновка | При 568×320 старая карточка кубика обрезала русскую подсказку счётчика. Бросок виден во время события, значение остаётся в обязательном пояснении. Устаревшая карточка больше не вытесняет следующий шаг. |
| Прогресс | Удержанное пояснение переживает перезагрузку, смену языка, справку и выход в меню. Повторного броска, звука и изменения партии при этом нет. Подтверждённый перезапуск из меню начинает первый урок. Отмена оставляет прежний урок. В тестовом профиле рейтинговая партия и Elo сохранились. |
| Звук приёмки | Одно из изолированных окон проверки было запущено со звуком и проигрывало события на Mac. Окно закрыто, дальнейшая визуальная проверка использует `--mute-audio`. Прогон Playwright направляет нативный Web Audio на беззвучный выход, а анализатор по-прежнему проверяет двоичный аудиобанк, расписание ударов и гашение при отмене. |

Кадры сделаны на реальном WebGL в Chrome с ANGLE Metal на Apple M5. Скриншоты, видеокадры и трассы хранятся локально в `.qa/` и исключены из Git.

## Команды проверки

```sh
npm ci
npm run check
npm run build -- --outDir .qa/tutorial-ship
npm run preview -- --host 127.0.0.1 --port 4177 --strictPort --outDir .qa/tutorial-ship
# В отдельном терминале
REMORSE_TEST_PORT=4177 npm run test:e2e -- --workers=2 --output=.qa/tutorial-final-verified
```

Node 26.3.0, npm 11.16.0, Playwright 1.65.1. TypeScript, ESLint, production build и **215 модульных тестов в 12 файлах** прошли. В полном прогоне финальной сборки прошли **86 браузерных тестов**, по 43 в Chromium и WebKit. Проверки охватывают девять уроков и оба завершения в каждом языке, старый чекпоинт 3→4, переход на обычный RNG и реального бота, 2D и уменьшенное движение, отмену активного броска и таймера возврата, отсутствие повторного броска при восстановлении, работу рейтинга и сохранений.

Отдельный аудит компоновки в установленном Chrome загрузил 82 учебных состояния на каждом языке через IndexedDB. В 1440×900, 1280×800, 1512×715, нативном окне 1200×710, 390×844, 360×800, 844×390 и 568×320 заголовок, объяснение, правило и обязательные действия помещались без прокрутки. Наименьшая клетка 2D на 568×320 была около 22 CSS-пикселей.

На [127.0.0.1:4173](http://127.0.0.1:4173/) и [Wi-Fi адресе Mac](http://192.168.31.44:4173/) проверены HTML финальной сборки, загрузка 3D и начало первого урока из отдельного профиля Chrome. В обычном Chrome открылась сохранённая позиция урока 3 с новой подсказкой. Сохранённый выключенный звук подхватился из настроек браузера.

Физический iPhone в CoreDevice был недоступен. Мобильные размеры и касания проверялись в Chrome и Playwright WebKit. Для общего 3D-модуля Vite сообщает 542,56 кБ до gzip. Замера FPS на физическом телефоне нет.
