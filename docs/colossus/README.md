# Колосс / COLOSSUS

Шахматная экспедиция против босса: восемь фигур с HP, объявленные заранее атаки, расходуемые щиты, броня, карты и командные действия. Чистые правила — в `games/chess/colossus/src/core`, клиент — в `src/ui`, кооперативный сервер — в `apps/server/src/colossus`.

Основание: [полные правила](../chess-2/COLOSSUS_RULES.md), [дополнение о картах босса и редкости](CARDS_AND_PRESENTATION.md). Фактические проверки и ограничения выпуска записываются в [BUILD_STATUS](BUILD_STATUS.md). Художественная система и происхождение ресурсов: [ART_DIRECTION](ART_DIRECTION.md), [ASSETS](ASSETS.md).

## Запуск из репозитория

Требуется версия Node, указанная в корневом `package.json`.

```sh
npm ci
npm run colossus:dev
```

Одиночная игра открывается на `http://127.0.0.1:5195/`. Для кооператива в другом терминале запустить сервер с отдельным каталогом разработки:

```sh
npm run build:server
HOST=127.0.0.1 PORT=4195 DEV_ORIGINS=http://127.0.0.1:5195 DATABASE_PATH=.qa/colossus-dev/remorse.sqlite OVERDRIVE_DATABASE_PATH=.qa/colossus-dev/overdrive.sqlite COLOSSUS_DATABASE_PATH=.qa/colossus-dev/colossus.sqlite node dist-server/main.js
```

Vite перенаправляет `/api` на этот сервер. При другом адресе сервера задать `COLOSSUS_API_ORIGIN` перед запуском клиента. Для двух независимых командиров нужны разные браузерные профили или устройства: вкладки одного профиля используют одну гостевую cookie.

Общая production-сборка:

```sh
npm run build
npm start
```

В общей сборке Колосс находится по `/colossus/`, REMORSE по `/`, OVERDRIVE по `/overdrive/`. Команды собирают и запускают локальное приложение; они не выполняют публикацию на внешний хостинг.

## Прослушивание звуков

```sh
npm run colossus:audio:build
npm run colossus:audio:preview
```

Открой [звуковое демо](http://127.0.0.1:5196/audio-review.html). Здесь можно отдельно прослушать все 17 эффектов и семь сочетаний на игровой громкости. У каждого звука есть решение «Утверждаю» или «Доработать» и поле для замечания. Решения сохраняются в этом браузере для текущего WAV. Кнопка «Скачать решения» выгружает их вместе с идентификаторами файлов.

[Демо «Броня и щит»](http://127.0.0.1:5196/audio-variants.html) сравнивает текущий звук и три новых варианта для каждого из двух эффектов. Кнопка «В бою» проигрывает последовательность через игровой микшер. Выбор в этом демо сохраняется отдельно от решений по всему набору.

Владелец выбрал A «Круглый щит» и A «Мягкий блок»; оба файла установлены в звуковой банк v3. [Источник выбора и точные SHA-256](AUDIO_SELECTION_2026_11_28.md). Файлы сравнения и сохранённый выбор A продолжают использовать прежние ID и хеши.

Сборка демо лежит в `.qa/colossus-audio-review/dist` и слушает только локальный интерфейс Mac.

## Что делает игрок

За раунд выдаются три команды; на начальной сложности — четыре. Одна фигура выполняет одну обычную команду: движение, атаку либо оборону. Атака наносит урон без автоматического уничтожения атакующего. Конь после удара выбирает клетку отхода. Король имеет 20 HP; шах и мат не используются.

Замысел босса уже известен до команд игрока. Подсветка и прогноз урона помогают разобрать луч, движение, площадь или огонь. После подготовки игрок явно запускает ответ босса. Каждые три боевых ответа босс восстанавливается: новых атак нет, а атаки армии усиливаются на 1. Сохранившийся огонь всё ещё опасен.

В охоте победа достигается снятием брони и HP выбранного босса. Гибель короля, сдача или истечение 24 раундов завершают попытку поражением. В кампании нужно последовательно победить Регента, Шпиля и Архивариуса; ранения и потери переходят между боями, а два лагеря дают восстановление и выбор дополнительной помощи.

## Карты

Доступны 16 карт игрока; в боевую колоду выбираются 12 с ограничением редкости. Три стартовые карты фиксированы. Со второго раунда игрок получает по одной карте, пока конечная колода не исчерпана. Рука ограничена пятью; лишнюю карту выбирает сам игрок. За фазу разрешена одна карта, оплачиваемая фокусом отдельно от команд.

Вся поверхность карты показывает редкость: камень, лазурит, аметист или золото. Дополнительно используются название редкости, узор и печать. На каждой карте собственная иллюстрация. Карты босса имеют отдельную коронованную печать.

У каждого из трёх боссов ровно три разные особые карты. Добор — на раундах **3, 8 и 13**, без повторного использования. Босс объявляет эффект вместе с замыслом; выбранные клетки не меняются в ответ на уже совершённый ход игрока. Во время восстановления карта ожидает следующей боевой фазы. В настройках боя карты босса можно отключить; это отдельная категория результата.

## Режимы и сохранения

Охота, кампания, практика с редактором позиции; четыре сложности; одиночная игра, два командира на одном устройстве и сетевой кооператив. Обучение состоит из семи коротких интерактивных упражнений на том же ядре правил. Собственный учебный босс — Смотритель; он не встречается в обычной охоте, походе или сетевых комнатах. Последний урок завершается настоящей победой после превращения пешки и усиленного удара в фазу восстановления. Доступны русский и английский языки, 3D/2D, звук и сокращённая анимация.

В кооперативе армия разделена между A и B, команды чередуются. Карты и фокус общие; карту играет ведущий раунда. Досрочное завершение фазы и сдача требуют согласия обоих. Разрыв связи приостанавливает совместную игру. После 60 секунд отсутствия партнёра оставшийся игрок может явно принять полное управление; возвращение требует согласия и границы раунда.

Локальные сохранения используют отдельные ключи `colossus.*`. Сетевая партия хранится в отдельной SQLite-базе; сервер сохраняет результат команды вместе с её квитанцией. Повтор потерянного запроса не расходует вторую команду. Будущий порядок колод и seed не отправляются клиентам.

Колосс доступен из портала как самостоятельная гостевая игра. Общие аккаунтные комнаты и адресные приглашения платформы не объявляются подключёнными к этому игровому runtime.

## Следующие боссы и игры

Обычный список противников выводится из `BOSSES`, а паттерны, восстановление, сближение и особые карты подключаются через `BOSS_BEHAVIORS`. Новый босс не требует переписывать общий ход раунда. Поход сохраняет свою явно заданную последовательность. [Рецепт расширения и проверенные ограничения](CORE_AUDIT_2026_11_27.md) дополняется [правилами создания GLB и SVG](ASSETS.md).

Гостевой каталог, сборка, SPA-маршруты и проверки выпуска берут игры из `packages/game-registry/games.json`. Новая законченная игра подключается одной записью и своим workspace; автодеплой выполняется по существующему процессу после разрешённого объединения в main. [Подробности регистрации](../iva-games/GAME_REGISTRATION.md).

## Проверки разработчика

```sh
npm run colossus:test
npm run server:test
npm run check
npm run build:all
npm run workspace:smoke
node games/chess/colossus/scripts/colossus-balance.mjs
```

`colossus-balance` проигрывает реальные позиционные партии через ядро и повторяет журналы действий. Это воспроизводимая проверка правил и одной автоматической политики, а не измерение человеческой сложности. Сырые журналы, временные базы и снимки экранов остаются в игнорируемой `.qa`.

Для развёрнутого сервера нужно сохранять все три игровые базы на постоянном диске. Согласованную копию базы Колосса следует делать тем же SQLite backup API, который используется для других баз проекта, задавая фактический `COLOSSUS_DATABASE_PATH`; копирование только основного файла при активном WAL не является такой копией.

Подготовленный Compose задаёт отдельный `/data/colossus.sqlite` в общем постоянном томе chess-data. Скрипт `deploy/iva-games/backup.sh` после чистой остановки копирует весь каталог и проверяет присутствующую третью базу; совместимость со старыми образами двух игр сохраняется. Эта конфигурация не означает, что внешний сервер уже развёрнут.
