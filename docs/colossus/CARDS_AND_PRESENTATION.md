# Колосс — карты босса и оформление редкостей

Дата: 26 ноября 2026 года, Москва. Дополнение к `docs/chess-2/COLOSSUS_RULES.md` для первой кодовой версии.

## Источник решения

Прямой запрос владельца: красивые карты; редкость обязательно видна по фону; у каждого босса около трёх запоминающихся карт необычных действий; карты босса выдаются реже карт игрока. Ниже — конкретная формализация ChatGPT для реализации этого запроса. Новые эффекты ещё требуют позиционной проверки вместе с основным боем.

## Получение и объявление

- У каждого босса ровно три уникальные собственные карты, каждая доступна один раз за бой. Их каталог и эффекты можно посмотреть до охоты.
- На старте рука босса пуста. Добор — в начале раундов **3, 8 и 13**, по одной карте. Это реже добора игрока каждую подготовку со второго раунда.
- Порядок этих трёх карт перемешивается воспроизводимо отдельным потоком seed, не меняя порядок колоды игрока. Перезагрузка не даёт новый порядок.
- Полученная рука босса открыта. Скрывается только порядок будущего добора.
- При планировании боевого ответа босс может применить одну имеющуюся карту. Эффект и все клетки/условия включаются в точное объявленное намерение до действий армии.
- Карта расходуется при объявлении, даже если игрок затем сорвал атаку. При отсутствии допустимого плана остаётся в руке.
- Восстановление нельзя заменить картой. Добранная в такой раунд карта ждёт следующего боевого намерения. Счётчик трёх боевых ответов не сбрасывается.
- Карты не используют фокус армии, не повторяются и не создают дополнительные скрытые действия после завершения намерения.
- В настройках можно отключить карты босса. Этот выбор фиксируется на начало охоты/похода и входит в категорию рекорда; включение по умолчанию.

## Каменный Регент

| ID / название | Эффект |
|---|---|
| `regent_reposition` — Смена опоры | Заменяет обычный боевой приём: шаг тела на одну клетку по стороне без контактного урона, затем при успешном шаге Гонг с уроном 2 вокруг нового тела. Живой блокер срывает шаг и зависимый Гонг. |
| `regent_far_gong` — Дальний гонг | Заменяет приём неподвижным ударом по внешней рамке на расстоянии Чебышёва ровно 2 от тела; урон 2. Ближнее кольцо остаётся вне этого удара. |
| `regent_crossfire` — Двусторонний раскол | Заменяет приём неподвижным залпом по двум противоположным сторонам тела: по два параллельных луча с каждой стороны, каждый до первого заслона с уроном 2. Это одна одновременная атакующая группа. |

## Шпиль

| ID / название | Эффект |
|---|---|
| `spire_retreat` — Скользящий отход | После обычного приёма добавляет один обычный шаг в объявленную соседнюю клетку без контакта. Шаг привязан к ожидаемой конечной клетке основного приёма: если предыдущая посадка/маршрут сорвались и босс её не достиг, отход отменяется. Занятая конечная клетка также отменяет отход. |
| `spire_fork` — Коневая вилка | Последняя атакующая группа обычного приёма заменяется ударом на 2 по восьми клеткам хода коня из ожидаемого положения босса. Сохраняются условия выполнения этой группы; если требуемое движение сорвано, вилка не переносится в другое место. |
| `spire_bent_dash` — Ломаный выпад | Заменяет приём: начальная насечка лучом на 1, затем рывок из двух перпендикулярных ортогональных частей суммарной длиной не более 3 клеток, затем конечный луч на 2 при полном завершении маршрута. На пути контакт 1, первый выживший блокер останавливает рывок. Все клетки, направление поворота и оба луча объявляются заранее. |

## Пепельный Архивариус

| ID / название | Эффект |
|---|---|
| `archivist_parallel` — Двойная строка | Заменяет новое огненное заклинание двумя различными параллельными полными вертикалями либо горизонталями. Перемещение и условие успешной посадки основного приёма сохраняются. |
| `archivist_cross` — Перекрёстная правка | Заменяет новое заклинание одной полной вертикалью и одной полной горизонталью. Пересечение получает одно попадание в этом пакете. |
| `archivist_border` — Обугленный край | Заменяет новое заклинание огнём по внешнему периметру доски. Угловая фигура получает одно попадание в пакете. |

Каждое новое огненное заклинание наносит 1 сейчас и 1 при догорании после следующей фазы армии. Дедупликация идёт по ID фигуры внутри пакета. Старый огонь и новое заклинание остаются разными пакетами, их общий урон отображается в прогнозе. Полную линию, уже целиком горящую при планировании, повторно выбирать нельзя, даже если она является частью старого составного огня. Уникальный периметр не выбирается, если он целиком уже горит.

## Фон, рамка и читабельность

Редкость выражается одновременно фоном всей карты, характером рамки, узором и явно написанным названием. Маленькой цветной точки недостаточно. Название, эффект и цена должны оставаться читаемыми поверх иллюстрации.

Предлагаемые семейства материала: обычная — состаренное серебро/графит; редкая — глубокая бирюза и гравировка; эпическая — аметистовая эмаль; легендарная — тёплое золото и янтарный свет. Финальные токены и реальные изготовленные ресурсы фиксируются в `ART_DIRECTION.md` и `ASSETS.md`.

Карты босса получают собственную маркировку владельца и символ босса, не копируют ресурсную цену игрока и не притворяются доступными для розыгрыша человеком. Карта, добавленная к текущему намерению, показывается рядом с названием приёма; её эффект можно раскрыть до завершения фазы.

Иллюстрации индивидуальны по эффекту, а материал фона последовательно показывает редкость. Неактивная карта сохраняет различимость редкости; блокировка обозначается дополнительным состоянием, а не одинаковой серой заливкой всех карт.

На сенсорном экране первое нажатие раскрывает эффект и выбор цели. Эффект не применяется от простого открытия карты. Поддерживаются клавиатура, видимый фокус и reduced motion; редкость никогда не кодируется только цветом.
