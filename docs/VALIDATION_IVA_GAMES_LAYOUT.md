# Iva Games — завершение пакетного переноса

25 ноября 2026 года. Этот отчёт относится к вложенной структуре в коммите, добавляющем документ. Его ревизию можно получить командой `git log -1 -- docs/VALIDATION_IVA_GAMES_LAYOUT.md`.

## Основание и результат

Продолжена существующая работа, а не заново созданная реализация:

- SDK и Форсаж: опубликованный `b71fad3ee6579c09d6a2f4df8e5628e243e10971`.
- Найденный неопубликованный локальный перенос: `9ecf362`, содержащий четыре npm workspaces и первоначальный `VALIDATION_MONOREPO.md`.
- Решения Iva Games, «Район» и «Гавань»: документационная ветка `docs/iva-games-platform-and-concepts`, `635520cb408d17d1361d30cf154fbc0a95f40c87`.

Шахматные игры размещены в `games/chess/remorse` и `games/chess/overdrive`. Общий поиск остаётся в `packages/engine-sdk`, сервер — в `apps/server`. Корневой npm-пакет называется `iva-games`; действующие package IDs `@chess-2/*`, игровые идентификаторы, версии, сохранения, cookie, базы и публичные маршруты не переименованы.

Интегрированы документы будущей платформы и концепции двух нешахматных игр. Портал, аккаунты, друзья, session-kit, Telegram-доставка и новые игры остаются спецификациями. Пустые npm-пакеты вместо их реализации не создавались. Противоречия в AGENTS, README и документации доменов разрешены с сохранением обоих направлений работы.

Поставка этой итерации — `feat/overdrive-sdk` / draft PR №3. Во время работы подтверждено выполненное владельцем переименование GitHub: текущее имя `decorum-guy/iva-games`, repository ID `1469444922` сохранён. Старое имя — `decorum-guy/remorse-chess`. Слияние в main, изменение DNS и активация Mac-сборки не входят в выполненную миграцию.

## Фактически повторённые проверки

Среда: Linux, Node.js 24.22.3. Проверки выполнялись на отдельной копии и временных базах, без видимых окон и звука. Все перечисленные команды завершились с кодом 0:

```sh
npm install --package-lock-only --ignore-scripts --no-audit --no-fund
npm ci --no-audit --no-fund
npm rebuild better-sqlite3 --foreground-scripts
ONLINE_TEST_PORT=36639 npm run check
npm run build
WORKSPACE_SMOKE_PORT=41203 npm run workspace:smoke
OVERDRIVE_SMOKE_PORT=34127 npm run overdrive:smoke
npm run auditions:build
npm run typecheck --workspaces --if-present
npm run test:e2e -- --list
npm run overdrive:e2e -- --list
npm run auditions:test -- --list
```

Отдельная пересборка `better-sqlite3` потребовалась потому, что локальный npm не исполнял её install script автоматически; после неё использовалась настоящая файловая SQLite.

## Оставшаяся приёмка

- В этой итерации браузерные сценарии не исполнялись. WebGL, движение, слышимый микс, полный пользовательский проход обучения и физический телефон не объявляются принятыми.
- Dockerfile обновлён и проверен чтением; Docker-образ здесь не собирался, поскольку Docker недоступен.
- Действующая REMORSE владельца на 4173, её профиль, партия, рейтинг, уроки и mute не менялись.
- Публичный сервер, два поддомена, TLS и внешняя сеть этой миграцией не проверялись.
- Прежние ограничения proxy rate limit и пересылки полных историй не исправлялись в рамках структурного переноса.
