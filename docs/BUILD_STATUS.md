`npm run check` и production build прошли. **189 модульных тестов**, **62 браузерных теста** в Chromium и WebKit. Визуальная приёмка и повторная проверка исправлений проведены отдельным агентом `gpt-6.1-terra` / `high` в открытом Chromium на Mac. Реальный Web Audio измерен. Прослушивание через динамики и проверка на физическом iPhone остались открыты. Исходные записи, скриншоты и трассы тестов хранятся в локальной `.qa/`.

## Запуск

Production-превью на Mac использует `http://127.0.0.1:4173/` и текущий Wi‑Fi адрес `http://192.168.31.44:4173/`. Существующие сохранения остаются в профиле Chrome. Если превью нужно запустить после перезагрузки, команды есть в [README](../README.md). Повторять приёмку новой ревизии следует на отдельном порту, чтобы сначала проверить её и затем обновить пользовательский запуск.
