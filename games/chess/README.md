# Chess 2 — шахматная коллекция Iva Games

Это **целевая организационная папка** по решению владельца от 25 ноября 2026 года. В данном документационном изменении игровой код в неё не перенесён.

| Путь после интеграции | Игра |
|---|---|
| games/chess/remorse | REMORSE |
| games/chess/overdrive | OVERDRIVE / Форсаж |
| games/chess/<variant> | Другие выбранные шахматные варианты после своих этапов разработки |

Владелец хочет добавить ещё 2–3 варианта. Сохраняются ранее выбранные Форсаж, Джокер, Хор, Химера и Связь; Эстафета не возвращается в план автоматически. Это не поручение одновременно реализовать все варианты.

Свой стиль, модели, звуки и интерфейс обязательны для каждой игры. Общий engine-sdk остаётся библиотекой поиска для поддерживаемого класса задач; hidden-information варианты требуют отдельной модели.

collectionId=chess служит для каталога. Игровые ID, правила сохранения, домен chess-2.online и его поддомены не меняются из-за добавления уровня каталога. Старые локальные профили, Elo и гостевые комнаты сохраняются.

Перед переносом прочитать фактическое состояние параллельного пакетного рефакторинга. Изменять пути импортов, glob workspaces, build/server/Docker/ресурсов и тестов согласованно. Нельзя создавать вторую расходящуюся копию той же игры.

Общий план — [Iva Games](../../docs/iva-games/README.md), архитектура — [ARCHITECTURE](../../docs/iva-games/ARCHITECTURE.md).
