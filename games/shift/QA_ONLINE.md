# Сдвиг: проверка онлайн-матча

Источник этого журнала — выполненные локальные команды, ответы обычного HTTP/WS API и наблюдения настоящего Chromium. Это не воспоминания о ручной игре. Автоматизация отдельно отмечена ниже; личная игра человека, физический телефон и реальное прослушивание здесь не заявляются.

## Воспроизводимый стенд

```sh
npm run build:foundation
node games/shift/scripts/online-browser-acceptance.mjs --cycle 1
node games/shift/scripts/online-browser-acceptance.mjs --cycle 2
```

Скрипт запускает собранный platform и Chromium дочерними процессами в одном процессе Node. Используется отдельный loopback-порт `4408`; можно передать `--port` или `SHIFT_QA_PORT`. Выбор браузера: `SHIFT_BROWSER_EXECUTABLE`, локальный официальный headless Chromium, затем Chromium, установленный Playwright. CI устанавливает браузер обычной командой `npx playwright install --with-deps chromium`.

Каждый запуск создаёт свежие приватные SQLite, файловый почтовый ящик и два настоящих аккаунта через регистрацию, пароль, ссылку подтверждения и сессию существующей платформы. Затем используются действующие friendship/invitation/join/room/bot/settings/ready/start API. Почта остаётся в локальном файле, Telegram выключен. Проверочный код не редактирует авторитетное состояние движка, результат, таймеры, состав SQLite или разрешения аккаунтов.

Каждый матч открыт в двух независимых Chromium context с разными cookie-профилями. Кнопки лобби, выбор команды/роли, удаление/добавление ботов, готовность, старт, интерфейс штурмана и реванш проверяются настоящими действиями Playwright. Для продолжительных обычных матчей используется опубликованная политика ботов, которая получает только снимок, уже разрешённый данному браузеру. Она отправляет стандартные команды через тот же авторизованный WebSocket. Это **браузерная и сетевая автоматизация**, не личное прохождение человеком. Остальные участники — штатные серверные боты. Матч идёт в реальном времени 30 Гц, без ускорения авторитетного сервера.

Полные онлайн-матчи этой матрицы выполняются в Canvas 2D. Отдельные проверки 2.5D и обоих ракурсов находятся в журнале визуальной приёмки. Программный SwiftShader не считается проверкой производительности физического устройства.

Матрица одного успешного автоматизированного цикла: Крановый цех, Калибровка и Склад модулей, каждый в 2×2 и 3×3. Проверяются обычная доставка до результата, обе роли через ротацию, разные разрешённые виды клиентов, только допустимые сведения о скрытом противнике, конкурирующие сдвиги, переподключение в пути и возврат к лобби с новым матчем после реванша.

Полные сырые отчёты, разрешённые сетевые снимки и PNG остаются в игнорируемой `.qa/shift-online/`. Сессии, почтовые ссылки и базы не попадают в Git или CI artifacts. В отчёте сохраняются исходный git SHA и SHA-256 фактически использованных сборок, поскольку локальный цикл может идти до коммита.

## Предварительные прогоны

Полный цикл пока не засчитан.

1. `cycle-preflight-U4Mzcv`: обнаружена ошибка селектора самого проверочного скрипта — `EN` совпал с переключателем портала и переключателем игры. Исправлено ограничением `.shift-lobby`; игровой дефект не заявляется.
2. `cycle-preflight-ONztjC`: фактически пройдены изменения команд и ролей, удаление/повторное заполнение бота, фокус модального окна, RU/EN, готовность обоих аккаунтов и старт. На первом снимке двух одновременно работающих 3D-контекстов истекло ограничение 12 секунд. Переведены продолжительные онлайн-прогоны в 2D, отдельная визуальная приёмка 3D сохранена. Это ограничение программного графического стенда, не измерение физического GPU.
