## Что реализовано

В коде есть авторитетное ядро трёх карт, стрельба/инструменты/строитель/дроны, личная экономика, строительство/питание/станции, транспорт/разгрузка/возрождение, фильтрация видимости и результаты операций/матча. Клиент поддерживает RU/EN, 3D/2D, keyboard/pointer/touch, семь изолированных уроков и возврат в сохранённую партию. Сеть использует отдельный runtime, SQLite, Ed25519 admission, однократные билеты, поколения управления, долговечные receipts/outbox и архивы точных версий.

Реализованы durable FIFO, 15-секундные reservations, один ожидающий старт на хозяина комнаты, admission по ресурсам и ограниченное объединение FULL-коммитов. Без принятого измеренного профиля действует консервативный лимит одной комнаты. Тестовые профили не разрешены в production и не служат заявлением о мощности VPS.

Собственный комплект: **151 арт-файл**, 52 GLB стандартной/облегчённой детализации, 29 WAV, иконки, эффекты, три превью карт и локальные лицензированные шрифты. Исходники генераторов, лицензии и структурная проверка есть в [арт-реестре](art/ASSET_REGISTER.md). Все 52 текущих GLB импортированы и осмотрены на статическом Blender-листе; в одном ракурсе явных пропавших частей или крупных отверстий не обнаружено. Native Web Audio декодировал и воспроизвёл проверяемые голоса. Визуальная оценка наполненной игры агентом и прослушивание не выполнены.

## Открытые проблемы и подготовленные исправления

**SERVER_BUSY не исправлен.** R5 FP01/2D: worker work p99 0.8 ms, commit RPC p99 113.5 ms при кадровом интервале 16.7 ms и нуле Long Tasks. Отдельная R5 storage-диагностика наблюдала plain-file fsync p99 118.640 ms, а полный Store.commitBatch call p99 18.818 ms без tracing и 13.538 ms с tracing. Она использовала другой CI VM и короткое окно. Это подтверждает задержки записи вне игры, но не доказывает причину каждого map failure. FULL, publication boundary и пороги перегрузки сохранены.

**Default 3D медленный на SwiftShader.** FP01 frame gaps p50/p95 266.8 / 350 ms, измеренный callback сцены 2.4 / 5.4 ms. Камера, анимация, эффекты и render submit не объясняют остаток. React render/commit, async model completion и GPU completion не измерены полностью; источник задержки ещё не установлен.

**Focus acceptance открыта.** Оба headless драйвера подтвердили начальный фокус, но не дали настоящего blur/hidden после переключения. Проверки отпускания огня после этого события не выполнялись. Исходный сценарий перенесён в отдельные обязательные headed Chromium/WebKit Xvfb jobs; это подготовленный повтор, не PASS.

После R5 исправлена узкая ошибка collector: разрешено менять только 8-символьные токены двух точно ожидаемых JS/CSS тегов, все остальные байты закреплены canonical SHA. Исходные ответы сравниваются до нормализации, точные health/catalogue проверки и настоящий host-volume preflight сохранены. 20 focused tests и новое фактическое публичное чтение прошли; Docker-повтор ожидается.

Отдельный найденный дефект финальной фазы: после задержанного durable commit планировщик мог переписать finished/abandoned/pendingOutcome-paused в SERVER_BUSY. Guard ограничен продолжающейся running-симуляцией. Контролируемая 1500 ms задержка подтверждения writer RPC воспроизвела 3 FAIL до правки; после неё 11/11 publication tests PASS, включая неизменную overload-защиту для running. Это fault injection, а не измерение 1500 ms fsync, и не объяснение остановок карт на подготовке. Новый runtime artifact ещё должен быть собран и проверен.

Для следующего FP01/2D CI подготовлена ограниченная числовая корреляция настоящего runtime: конкретный tick связан с commit RPC и всеми служебными writer operations. Максимум 2048 строк / 256 KiB / 60 s, вывод после первой durable overload pause, без payload и domain IDs; production всегда выключен. Отдельные 26 focused tests (8 trace / 11 publication / 7 auth-store), TypeScript и ESLint прошли. Это проверка механизма записи, а не наблюдённый storage stall; новый реальный capture ещё не выполнен. [Схема и ограничения](../../docs/iva-games/REALTIME_QA_TRACE.md), [точный source checkpoint](qa/runtime-correlation-implementation.json).

## Непринятые обязательные области

Обе прежние четырёхкомнатные часовые попытки завершились раньше часа с overloadPause; последняя — 1084.328 s / 14 матчей. R4/R5 workloads не стартовали. Полная state-матрица 64 групп UI, все три карты в 3D, повтор партии, скрытая информация в пикселях/эффектах/звуке/статистике, физический телефон, прослушивание, настоящая потеря IP-пакетов, 24-часовой wall-clock recovery и production backup/restore не приняты. Последняя 14-профильная RTT-матрица и 1/5/8/15 s обрывы относятся к отдельно указанным более ранним артефактам.

Доступный агенту cloud browser не видит loopback сервера изолированной команды. Запрос запуска вне sandbox был автоматически отклонён политикой `sandbox_approval:false`; установленный Chromium wrapper не содержит браузер, стандартная установка Playwright вернула 403. Обход ограничений не выполнялся. CI-браузеры доступны, их фактические результаты приведены отдельно.

Для третьего публичного сервиса требуется штатная host-интеграция. Административный SSH-доступ в этой сессии не установлен; существующий ForceCommand не предоставляет provisioning третьего сервиса, Caddy, ключей и томов. Его права не расширялись. Обычный two-image deploy и имитированный ответ ACTIVE не подтверждают выпуск. Нужны фактическая успешная активация и публичная проверка; их здесь нет.
