# REMORSE

Веб-версия Remorse Chess: выразительная 3D-доска, десять уровней ИИ, локальный Elo, режим для двоих и интерактивное обучение. Ноутбук и телефон, русский и английский — обязательны.

## Текущее состояние

**Подготовлено задание для автономной реализации на Mac. Сама игра пока не реализована.** Этот коммит содержит исходные правила, цифровую спецификацию, визуальное направление, проверенные источники моделей и критерии приемки. Он не утверждает, что приложение или его тесты уже существуют.

## Что должно получиться

- Полная Remorse-партия с корректными состояниями, кубиком, аурами, обращением и дополнительными ходами.
- Настоящий Remorse Engine с десятью уровнями и предварительными внутренними оценками ≈400–2200 Elo Remorse, работающий без внешнего платного API.
- Локальный рейтинг игрока: старт 1000, начисление и списание по результатам рейтинговых партий; отдельный режим тренировки.
- Локальный режим на двоих.
- Обучение через действия игрока; после него — доиграть текущую позицию без рейтинга либо начать новую игру.
- Значки взятых фигур под никами обоих игроков и отдельный `+N` преимущества по материалу.
- Качественная 3D-графика, эффекты на поверхности самих фигур и анимации, удобный интерфейс для ноутбука и телефона, рабочий 2D-режим.
- Полные русский и английский: интерфейс, обучение, справка, история и сообщения; смена языка во время партии.
- Сохранение, восстановление и воспроизводимые партии.
- Чистое общее ядро, которое позднее можно перенести на авторитетный сетевой сервер.
