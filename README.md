# REMORSE

Шахматы на мраморной доске, где у взятий есть последствия. Играйте вдвоём, тренируйтесь с Remorse Engine или ведите локальный рейтинг. В девяти интерактивных уроках можно познакомиться со всеми состояниями и доиграть последнюю учебную позицию против ИИ.

## Запуск

Нужен Node.js 22.12+, 24 или 26+ и современный браузер. Рабочая копия на Mac находится в `~/Developer/remorse-chess`.

```sh
cd ~/Developer/remorse-chess
npm ci
npm run build
npm run preview -- --host 127.0.0.1 --port 4173 --strictPort
```

Откройте [игру на Mac](http://127.0.0.1:4173/). Для разработки используйте `npm run dev`.

Для телефона в той же сети запустите preview с `--host <локальный IPv4 Mac>` вместо `--host 127.0.0.1` и откройте этот адрес на телефоне с портом `4173`. На Mac адрес Wi-Fi можно узнать командой `ipconfig getifaddr en0`, если Wi-Fi использует `en0`. Приложение можно размещать и на статическом сервере. Скопируйте содержимое `dist/` целиком, включая локальные модели, текстуры, шрифты и Worker.

## Игра

- **Играть с ИИ** — выберите сторону, уровень и режим. После первого основного хода рейтинговая партия идёт в зачёт. Elo меняется один раз по её результату. В тренировке доступны отмена, повтор и изменение сложности перед основным ходом.
- **Играть вдвоём** — два игрока на одном устройстве. Доступны отмена, повтор, сдача и ничья по соглашению.
- **Пройти обучение** — девять уроков с пояснением причин и последствий. После нового эффекта игра показывает фигуру и правило и ждёт подтверждения; затем предлагает проверить его ходом. Счётчик можно рассмотреть отдельно. После последнего урока начните новую партию или продолжите позицию в тренировке против ИИ уровня 4.
- Выберите фигуру, затем клетку. В 3D на компьютере можно перетаскивать фигуры. Клавиатурой наведите фокус на доску, выберите клетку стрелками и нажмите Enter или пробел. Escape снимает выбор.
- Под никнеймами показаны взятые вражеские фигуры. Значок `+N` отражает текущий перевес по материалу. В настройках доступны RU/EN, 2D/3D, камера, звук и экспорт/импорт партии.
- При настоящем броске объёмный кубик падает и перекатывается, затем показывает результат. Для человека, ИИ и второго игрока используется одна последовательность. В reduced motion вращение заменено коротким спокойным появлением.
- Звук переключается кнопкой в шапке; громкость находится в настройках. Новый профиль включает эффекты после первого жеста, сохранённое выключение остаётся выключенным. «Детали» открывают инспектор и историю; во время игры основная страница не прокручивается.
- Сохранения и Elo привязаны к браузеру и адресу игры. Примерные значения силы ботов от 400 до 2200 принадлежат внутренней шкале REMORSE.

## Проверка

```sh
npm run check
npm run build
npx playwright install chromium webkit
npm run test:e2e
```

Playwright запускает production preview, если подходящий сервер ещё не открыт. Для отдельного порта установите `REMORSE_TEST_PORT`, например `REMORSE_TEST_PORT=4175 npm run test:e2e`. Локальные артефакты проверки находятся в игнорируемой папке `.qa/`.
