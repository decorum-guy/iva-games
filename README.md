# REMORSE

Веб-версия Remorse Chess: выразительная 3D-доска, игра против ИИ, локальный режим для двоих и интерактивное обучение. Ноутбук и телефон — обязательные интерфейсы.

## Текущее состояние

**Подготовлено задание для автономной реализации на Mac. Сама игра пока не реализована.** Этот коммит содержит исходные правила, цифровую спецификацию, визуальное направление, проверенные источники моделей и критерии приемки. Он не утверждает, что приложение или его тесты уже существуют.

## Что должно получиться

- Полная Remorse-партия с корректными состояниями, кубиком, аурами, обращением и дополнительными ходами.
- Настоящий Remorse Engine с тремя уровнями, работающий без внешнего платного API.
- Локальный режим на двоих.
- Обучение через действия игрока; после него — доиграть текущую позицию либо начать новую игру.
- Качественная 3D-графика и анимации, удобный интерфейс для ноутбука и телефона, рабочий 2D-режим.
- Сохранение, восстановление и воспроизводимые партии.
- Чистое общее ядро, которое позднее можно перенести на авторитетный сетевой сервер.

После реализации разработчик должен обновить этот README фактическими командами установки, запуска и проверки. Не добавляй несуществующие команды или неподтвержденный URL до их проверки.
