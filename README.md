# Iva Games

Общий репозиторий браузерных игр. Chess 2 — шахматная коллекция внутри `games/chess/`; REMORSE и Форсаж уже разнесены по самостоятельным npm workspaces вместе с общим Engine SDK и сервером. У каждой игры свои правила, обучение, интерфейс, модели, материалы, эффекты и звуки. Общий поиск и инфраструктура не задают общий визуальный шаблон.

| Пакет | Что находится внутри |
|---|---|
| `games/chess/remorse` · `@chess-2/remorse` | REMORSE: мраморная доска, реакции на взятие, обучение, режимы с ИИ и двумя игроками. |
| `games/chess/overdrive` · `@chess-2/overdrive` | Форсаж / OVERDRIVE: энергия, шесть приёмов, собственная керамическая арена и новый интерфейс. |
| `packages/engine-sdk` · `@chess-2/engine-sdk` | Общий типизированный поиск и контракт Worker; адаптер и оценка остаются в игре. |
| `apps/server` · `@chess-2/server` | HTTP/WebSocket и независимые службы сетевых комнат обеих игр. |

Структура и границы пакетов — в [MONOREPO.md](docs/MONOREPO.md). Реализация поставляется через `feat/overdrive-sdk`, [draft PR №3](https://github.com/decorum-guy/iva-games/pull/3). Наличие кода в этой ветке не означает слияние в `main`, активацию на Mac или публикацию в интернете. [Статус Форсажа](docs/overdrive/STATUS.md) отдельно фиксирует незавершённую браузерную и слуховую приёмку.

Имя пакета корня — `iva-games`. GitHub-репозиторий уже переименован в [`decorum-guy/iva-games`](https://github.com/decorum-guy/iva-games); repository ID `1469444922` подтверждает, что это прежний репозиторий с сохранённой историей. Старое имя — `decorum-guy/remorse-chess`. Имена внутренних пакетов `@chess-2/*`, домены `chess-2.online` / `remorse.chess-2.online`, игровые ID и данные сохраняются. Локальная папка может оставить прежнее имя.

В проект добавлены спецификации общего портала с аккаунтами, друзьями и приглашениями, а также концепции «Района» и «Гавани». Портал, platform-service, session-kit и новые игры пока не реализованы; работающий фундамент должен предшествовать их продуктовой разработке.

## Установка и сборка

Нужен Node.js 24; допустимые версии также указаны в `package.json`. Все команды ниже выполняются **из корня репозитория**. Один `package-lock.json` закрепляет зависимости всех npm workspaces.

```sh
npm ci
npm run check
npm run build
```

`npm run build` проверяет TypeScript, собирает обе игры, объединяет их клиентские выходы и собирает Node-сервер. Общая папка `dist` сохраняет адреса REMORSE `/` и OVERDRIVE `/overdrive/`. Сервер запускается из `dist-server/main.js`.

Для отдельных задач:

| Команда | Результат |
|---|---|
| `npm run build:remorse` | Самостоятельный клиент REMORSE в `games/chess/remorse/dist`. |
| `npm run build:overdrive` | Самостоятельный клиент Форсажа в `games/chess/overdrive/dist`. |
| `npm run build:client` | Оба клиента и совмещённый выход `dist`. |
| `npm run build:server` | Серверный bundle `dist-server/main.js`. |
| `npm run remorse:test` | Модульные проверки REMORSE. |
| `npm run overdrive:test` | Модульные проверки Форсажа. |
| `npm run sdk:test` | Проверки общего поискового SDK. |
| `npm run server:test` | Проверки серверов и их интеграций. |

Эквивалент отдельной сборки пакета: `npm run build --workspace @chess-2/overdrive`. Публикация на отдельный домен требует подходящей конфигурации сервера/хостинга; построение папки `dist` само по себе не публикует сайт.

## Изолированный локальный запуск для приёмки

На Mac не заменяйте работающую игру на 4173 при проверке кандидата. Создайте отдельную рабочую копию актуальной ветки по [заданию локальному агенту](prompts/ACCEPT_OVERDRIVE_MONOREPO.md), выполните установку и сборку, затем запустите из её корня:

```sh
PORT=4185 HOST=127.0.0.1 \
DATABASE_PATH=./data/preview-remorse.sqlite \
OVERDRIVE_DATABASE_PATH=./data/preview-overdrive.sqlite \
npm start
```

Откройте [REMORSE](http://127.0.0.1:4185/) или [Форсаж](http://127.0.0.1:4185/overdrive/). Это адреса для приведённой команды, не утверждение о запущенном сервере в вашей среде. Если 4185 занят, выберите другой свободный порт и используйте его последовательно в адресах и настройках origin.

`npm start` запускает страницы, HTTP API и WebSocket. Базы кандидата из отдельной рабочей копии не заменяют базы действующей игры. Для запуска с `NODE_ENV=production` обязателен `PUBLIC_ORIGIN`; параметры и вариант публикации описаны в [серверной инструкции](apps/server/README.md).

Для телефона в той же сети выберите `HOST=0.0.0.0` и фактический LAN-адрес Mac; используйте этот адрес и в приглашении. Если задан `PUBLIC_ORIGIN`, он должен соответствовать адресу подключения либо входить в явно разрешённые origins. Два независимых игрока требуют отдельных браузерных профилей или устройств: обычные вкладки одного профиля разделяют гостевой cookie. Статический Vite preview сам не запускает сетевые комнаты.

По умолчанию `npm start` использует порт 4173 и базу `data/remorse.sqlite`. Сохраняйте запуск из корня; перемещение исходников в пакет не является поводом перемещать рабочие базы или менять ключи сохранений.

## Проверка и приёмка

```sh
npm run check
npm run build
npm run overdrive:smoke
npm run workspace:smoke
npx playwright install chromium webkit
REMORSE_TEST_PORT=5199 npm run test:e2e
npm run overdrive:e2e
```

Модульные проверки охватывают SDK, обе игры и серверы. Production smoke проверяет собранные файлы и настоящие HTTP/WebSocket-сессии. Playwright-наборы игр разделены; для Форсажа выделен порт 5198 и отдельные базы. Проверки выполняются headless и без вывода звука на динамики. Не направляйте тесты на личный профиль, порт действующей партии или рабочую базу.

Локальные скриншоты, видео, трассы и подробные журналы сохраняются только в игнорируемой `.qa/`. `--list` подтверждает обнаружение сценариев, но не их исполнение. Старые количества тестов, хеши JS и наблюдения в отчётах относятся к указанным там ревизиям, а не автоматически к переносу в workspaces.

[Отчёт вложенной структуры Iva Games](docs/VALIDATION_IVA_GAMES_LAYOUT.md) фиксирует проверки этой итерации. [Первоначальный отчёт миграции](docs/VALIDATION_MONOREPO.md) сохраняет результаты предыдущего локального переноса. [Задание локальному агенту](prompts/ACCEPT_OVERDRIVE_MONOREPO.md) объединяет проверку структуры, полный проход Форсажа, сетевую партию и подготовку одной демонстрационной вкладки. Действующая REMORSE на Mac остаётся отдельной принятой сборкой до явно согласованной активации.

## REMORSE: как играть

- **Играть с ИИ** — выберите сторону, уровень и режим. После первого основного хода рейтинговая партия идёт в зачёт. Elo меняется один раз по её результату. В тренировке доступны отмена, повтор и изменение сложности перед основным ходом.
- **Играть по сети** — создайте закрытую комнату, отправьте другу ссылку и подтвердите готовность. Игра поддерживает все правила REMORSE, общие броски, восстановление соединения, сдачу, предложение ничьей и реванш со сменой цветов. Это дружеский режим без часов и рейтинга. Перемотка истории не изменяет общую позицию.
- **Играть вдвоём** — два игрока на одном устройстве. Доступны отмена, повтор, сдача и ничья по соглашению.
- **Пройти обучение** — девять уроков с пояснением причин и последствий. После нового эффекта игра показывает фигуру и правило и ждёт подтверждения. Затем предлагает проверить правило ходом. Счётчик можно рассмотреть отдельно. После последнего урока начните новую партию или продолжите позицию против ИИ уровня 4. Если вы уже начали обучение, на главном экране можно выбрать «Пройти обучение заново» и подтвердить переход к первому уроку.
- Выберите фигуру, затем клетку. В 3D на компьютере можно перетаскивать фигуры. Клавиатурой наведите фокус на доску, выберите клетку стрелками и нажмите Enter или пробел. Escape снимает выбор.
- Под никнеймами показаны взятые вражеские фигуры. Значок `+N` отражает текущий перевес по материалу. В настройках доступны RU/EN, 2D/3D, камера, звук и экспорт/импорт партии.
- При настоящем броске объёмный кубик падает и перекатывается, затем показывает результат. Для человека, ИИ и второго игрока используется одна последовательность. В reduced motion вращение заменено коротким спокойным появлением.
- Звук переключается кнопкой в шапке; громкость находится в настройках. Новый профиль включает эффекты после первого жеста, сохранённое выключение остаётся выключенным. В обычной партии выбор фигуры сразу показывает её состояние и активные сроки; «Детали» открывают подробное объяснение и историю. Во время игры основная страница не прокручивается.
- Сохранения и Elo привязаны к браузеру и адресу игры. Примерные значения силы ботов от 400 до 2200 принадлежат внутренней шкале REMORSE.
